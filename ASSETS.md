# Documentation assets

The support workflow illustration and its editable source live in [docs/assets](docs/assets/README.md). The original diagram and animation use the repository's Apache-2.0 license. The bundled font has separate terms in [FONT-LICENSE.txt](docs/assets/readme-animation/assets/FONT-LICENSE.txt).

The website is maintained in a separate private repository. Its artwork is outside this source release and does not acquire a license from this repository.

## The decision demos' documents

[examples/decision-demos/documents](examples/decision-demos/documents/README.md) holds 24 PDFs made for the decision-workflow examples: certificates and articles of incorporation, IRS EIN letters in the CP 575 layout and bank account verification letters. Every company, person, officer, bank, address, file number and EIN in them is invented; none is a real person or a real customer. Each was rendered from HTML in headless Chrome, and `documents/labels.json` holds each file's ground truth, including the defects some carry on purpose. They use the repository's Apache-2.0 license.
