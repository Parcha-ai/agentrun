Open the console:

The token sets your password on the first screen. It's yours alone: don't share it.
  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.existingSecret | default .Release.Name }} -o jsonpath='{.data.AGENTRUN_TOKEN}' | base64 -d

Then Continue with ChatGPT, or add a model key (Settings, Model keys), and run your first agent.
Agents here get file tools and web_fetch, and no shell: a cluster gives the server no Docker. For a shell, add a sandbox
provider's key in the console.
