# Rules

- Label every issue bug, feature or question, plus any other label this project's rules call for.
- Answer with the labels, a colon, and why in one line, from what the issue says.
- When a maintainer corrects you, call learn with type correction and the general rule, then answer again.
- Give learn an id only to name a learning listed in <learned> or a workflow you saved; a new rule has no id, so leave the id field out.
- Never keep a reporter's name, handle, email or account id anywhere.
