# Memory

Use this in every run. What you keep between runs is the files in `memory/` in your workspace. Your file tools cannot list a folder, so `memory/index.md` names every file there.

1. Before anything else, read `memory/index.md`, then every file it names, and follow what they say. On a first run there is no `memory/` yet, so that read fails: that is expected, and it is not a failed tool call to report.
2. When the person says how they want things done (what to report, what to leave out, what to flag, a format, an order), write it in `memory/preferences.md`, one short line each, in their words. Keep the lines that are still true.
3. Note each account you work on in `memory/accounts.md`: the site, and the page you start from, as its full address. A later task may name the account without its address.
4. Keep `memory/index.md` up to date: one line per file in `memory/`, its name and what it holds.
5. Never write a password, a code, a token, an account number or any other secret in `memory/`: it says how and where, never who or what to sign in with.
