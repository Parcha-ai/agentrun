The console's Runs and Triggers pages say what to do on a server that has none yet. Runs says what a run is and offers the way to the first one: Start a run opens the Playground, and Browse templates opens the templates. Triggers names the three things that can start a run (a schedule, a webhook, GitHub), each with its own button. A filter that matches nothing still says so in one line.
