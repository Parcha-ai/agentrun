The console shows tool pins. Settings → Tools lists the tools this server pins under "Pinned tools", each as "Pinned: event must be left out or COMMENT; method must be one of create, delete_pending, submit_pending. Calls outside it are refused before they run or ask." The agent editor's tool row says the agent's own as "Pinned for this agent: …", adding "This server pins it too; both hold." where the server pins the tool as well, and the server's alone where only it does. A pin that doesn't read says "This pin doesn't read, so every call to this tool is refused. Set the pin again, or remove the tool's setting." The words follow the gate's order (arguments sorted; null first, then by value), so the screen and a refusal read alike. Pins are not edited here; a save keeps them as they are.
