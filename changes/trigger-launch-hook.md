Launch hook: with `AGENTRUN_LAUNCH_HOOK_URL` and `AGENTRUN_LAUNCH_HOOK_SECRET` set, each trigger firing that would start a run is POSTed to the host instead, signed as Standard Webhooks (`{firing_id, trigger_id, agent_id, revision_id, input, fired_at}`), and the host starts the run through the API with its own keys and cap. The host passes the new `trigger_firing` (`{trigger_id, firing_id}`) on `POST /agents/{agent_id}/runs`, so the run is the firing's: it carries the trigger, its title and input origin, and the firing reads `started` with it, counted by the overlap check and `max_active_runs`. The host may start the run before or after it answers: a 2xx without the run records the firing `sent`, and it still takes that one start until 10 minutes after its `fired_at`. Any other answer, or none in 10 s, records it `skipped` with why. The hook URL is https, or http to 127.0.0.0/8, `::1` or `localhost` alone; any other http URL stops the start. Unset, firings start their runs as before, and `trigger_firing` is refused.
