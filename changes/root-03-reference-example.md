New example, `examples/reference/` (`npm run demo:reference`): one program that composes the open packages on pi-durable and runs one job end to end with no key and no network but loopback. A disk run on a local directory, the workflow as one pi-durable task (`createWorkflowExtension`) with its LLM step on the node runner, the browser on its fake backend, vision's `read` and a scripted judge. `host.ts` declares what a host supplies as one value, `assemble.ts` wires it and `run()` returns the task's outcome (`complete`, `escalated`, `refused` with its code and message, or `stopped`). The tool door keeps its answers, so a run killed between a call's dispatch and its commit is settled from the answer before the driver opens; each judge's receipt is kept in the run's store and replayed by a resumed run; the gates read the run's store, not its status rows; and the scripted lead asks an errored read again, looks before asking a cut page action again and decides from the browser's details, and never cites a read of a page it did not open, `--json` prints the result as one object, `--dir` keeps the run so a second process resumes it, and `--chrome` drives a local Chrome that reaches only the job's pages. `examples/reference.test.mjs` pins the output and kills a run after the browser read, then resumes it. Its README lists the package gaps it works around.
