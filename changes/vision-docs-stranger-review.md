The vision docs, read again as a stranger would. Every page that starts a run says first that every run, free or live, needs `ffmpeg`, `ffprobe`, `pdftoppm` and `pdftotext` on the path (`brew install ffmpeg poppler`, or `sudo apt-get install ffmpeg poppler-utils`), and that the five examples whose files are not committed need `--fetch-sources` on fakes, with each download's size (120 MB to 342 MB). Each example states the default cost cap: a run stops past $1, twice its expected $0.50, unless `--max-usd` sets another. `FAL_KEY` is optional everywhere: with it the agent can transcribe a film's speech; without it, it works from the picture alone. The vision agent's README states what TypeSafe's Jev 1.14 post says about images and boxes (the `TypeSafe-Danger-Zone-Images: true` header, which the runner sends; the box type on `jev-1.14.0` only, which every judgment asks for; both experimental, and less accurate on images than on text) and links it. `SETUP-PROMPT.md` checks for a container or a VM first, names every example with its download, and points to console.typesafe.ai/keys. The `look` and `verify` skills tell the user which program is missing and how to install it, and never install it themselves. The pi-vision README opens with what the package does, cuts its status table to one paragraph, and glosses its terms (a look, Jev, the lead, a gateway, fakes) where they first appear.
