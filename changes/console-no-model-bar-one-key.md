When no default model is set, the console's no-model bar leads with saving a key in Settings where the server keeps keys (its key routes, with a seal key): "Add a key in Settings → Model keys (one OpenRouter key gives every harness its model), and it takes effect at once. Or set OPENROUTER_API_KEY, ANTHROPIC_API_KEY or OPENAI_API_KEY where AgentRun starts, and restart." Where the server keeps no keys, or has no seal key to keep one (`tool_keys.at_rest: "unavailable"`), it reads "Set OPENROUTER_API_KEY (one key gives every harness its model), or ANTHROPIC_API_KEY or OPENAI_API_KEY, and restart." When the server's `AGENT_MODEL` is set without its provider's key, an OpenRouter key does not run it, so the bar names that model instead: "This server's default model is <model>: add its provider's key in Settings → Model keys, and it takes effect at once. Or set it where AgentRun starts, and restart.", or, where the server can't keep a key, "…: set its provider's key where AgentRun starts, and restart." The bar for an `AGENT_MODEL` the server does not run is unchanged.
