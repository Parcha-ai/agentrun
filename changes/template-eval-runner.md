`agentrun template eval DIR` (`agentrun-serve eval-template DIR`) runs a template package's eval cases as real runs of its agent and grades each run, so a package's quality bar is measured. By default it runs on a server of its own in the command's process over a temp data directory, so it never touches yours; `--server URL` runs on that one, through its v2 API alone. Per case it serves each `mcp` fixture as a fake MCP server on loopback that records every call, applies the package with the case's parameters and grants (a fresh agent per run), seeds the case's learned notes, starts each run with the prompt and the case's cap, and grades the answer, the tool calls and the files: `schema`, `regex`, `tool_used` and `file_exists` deterministically, `llm` as a run of a blind grader agent on the same server (`--grader-model`). A case passes when every grader passes on every run. The summary goes to stdout and the whole report, with each run's and each grade's cost, to `--report FILE` as JSON; the exit is 0 when every case passed, 1 when one failed, 2 when nothing ran. Every case is read and checked before anything runs, and the tests check that every shipped package's cases load and their fixtures serve.
