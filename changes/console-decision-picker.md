The console's agent builder can create a decision agent: on a new agent, the harness picker lists **Decision** after Pi, Claude and Codex. Picking it makes the agent a workflow revision built from a starter decision workflow (one typed question, and a person for an unclear or low-confidence answer, adapted from the repository's jury demo; it has no code node, so a server started without `--allow-code-nodes` runs it), whose question goes to the server's decision provider: Jev, the default, or Parallel where Jev does not run, with no instructions, tools, thinking or model to fill in; after Create the agent opens on its Workflow step, where its nodes are edited. Decision is offered when the server's capabilities list the `runJudge` workflow adapter and Jev or Parallel among the decision providers available, and shown disabled with why otherwise, so the console never makes a decision agent whose run the server would refuse. The harness picker shows one column per choice on a wide screen. It is a choice in the console only: the revision names no harness, and the server is unchanged.
