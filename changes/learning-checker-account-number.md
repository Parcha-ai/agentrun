What a run proposes to learn is refused when it holds a bank account, IBAN, routing or sort-code number beside its word ("send refunds to account 4471-0098", "IBAN GB82 …", "routing number 021000021", "sort code 12-34-56"), as text shaped like a secret, whatever the grader made of it. A count of accounts, a date or a card's last four is not one. A file name refused for one (`account12345678.md`) is cut of the number wherever learning prints or serves it: the run's learning problems and the learning reads. A run's own view still shows its user such a number: only learning refuses and cuts it.
- Upgrading: nothing to change.
