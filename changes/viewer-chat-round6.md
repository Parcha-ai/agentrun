The chat view reads as a conversation: a run of steps that only ran a command folds into one quiet "ran N commands" line, and a step that made looks leads with them (each look's picture, what it asked, and the first sentence of its answer that says something), with the code behind a click.
The person's question is a plain bubble with the files as chips (four, then "+ N files") and any other fields behind "details"; the first screenful of pictures loads at once.
The chat view and the inspection view take agentrun.ai's look: square corners, no accent bars, the site's dark palette and its type. The agent's page is drawn in that look too, for presentation only: the recording keeps its own page byte for byte.
A thought shows a title only when its model wrote one (a headline in bold); any other thought folds whole under "Thought". A look's card shows its first picture that is not near-black, so a film's dark opening frame never leads.
