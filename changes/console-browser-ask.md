When a run's agent asks for you in its browser, the console shows the ask in Mission Control's Needs you and above the run's page: "The agent asks you to: …" and "Done when: …" (the agent's words, shown as plain text: no Markdown, no link, no HTML), the console's own line "You never need to type your AgentRun password for this.", and when the ask expires. The timeline's "Waiting for you" row reads "The agent asks you to: …" too. Both come from the run alone, so an ask still open after a restart shows on a fresh page load. The run page opens on its Browser tab, where Take over and Hand back sit in the viewer's own bar. Done and Cancel answer the ask (`POST /v2/runs/{id}/browser/hand-back`), once: a second click before the answer comes sends nothing. An answer that came second, or one after the ask expired (409 `handoff_answered`), reads the run again and says so; the words stay on the run page and in Needs you after the ask's card is gone. A 403 says to sign in with your password, which is the only way this route answers. While the ask waits, the message box says a message steers the run and doesn't answer the ask. The live view's frame now allows forms, so a take-over can use the viewer's address bar.
