packages: @parcha/agentrun-learn
kind: breaking
---
The package now describes an agent's learning folder in Claude Code's auto-memory format, and checks what a run proposes for it: new notes only. A host that called `checkRun`, `checkBranch`, `reflectBudget` or the `agentrun-learn` CLI moves to `checkProposal`, `reflectPrompt({ dir, active })` and `gradePrompt({ run, instructions, active, superseded, proposed })`.
- The folder is `MEMORY.md`, the index the host builds, and one `<slug>.md` per note with `name`, `description`, `type` and optionally `supersedes: [old.md]`; `status: superseded | retired` with `superseded_by` is the host's alone. `supersede(text, by)` marks an old note.
- `parseNoteFile`, `activeNotes`, `buildIndex`, `loadedIndex` and `indexLine` read and build the folder's format; AgentRun Server reads and builds an agent's folder with them.
- `checkProposal({ base, changes, refuseValues })` refuses an edited or deleted note, a path that is not a `.md` file at the folder's top, a bad name, a link or anything not a regular file, front matter out of shape, a run that sets `status`, a `supersedes` naming a note that is not active, more than 8 notes superseded, more than 8 new notes or a note over 4096 bytes, an index past 200 lines, hidden characters, non-UTF-8, and text shaped like a secret or holding one of the host's values, in a note or its name. A change to `MEMORY.md` is ignored. `mergeProblems` asks the merge's questions again of `main` at merge time.
- `redactSecrets` prints a field over 4096 bytes whole as `[redacted]`, never scanning it, so a long crafted path costs no quadratic scan.
- `GRADE_RUBRIC` asks four questions of each new note (general, from content, duplicate, contradicts); `parseVerdict(text, proposed)` reads one item per new note, `{ file, keep, question?, why }`, and fails closed as before.
- `gradePrompt` is bounded by construction, never by how many notes the folder holds: each active note's index line (`indexLine`, cut to 300 characters), the whole text only of the notes the proposal supersedes, the new notes, and the instructions cut to 16,000 characters. It stays under `GRADE_CAPS.prompt`, 200,000 characters, and throws past it.
- Cut: the `runs/<run id>` branch layout, `learnings/` and its `L-<hex>` notes and `INDEX.md`, memos and their sections, `uses/` receipts, skills and workflow drafts (with the DSL validation and the host tool list), the locked-path list, the `agentrun-learn` CLI and its git reader, and the dependency on `@parcha/agentrun-dsl`.
