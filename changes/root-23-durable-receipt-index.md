`@parcha/agentrun-pi/durable` keeps a run's paid receipts as a document: `ReceiptIndex` (the session document `agentrun.receipts`, document version 1, one entry per paid call keyed by tool and argument hash, with the paid result and the session that paid), `reuseReceipts({ tools, sessionId, answer, unknown })` and `seedReceipts(host, receipts, from)`. `reuseReceipts(...).wrap(tool)` records a paid call's result, answers a repeat of another session's call from the receipt and says so (when `answer` is set), and refuses a call equal to an effect whose outcome is unknown; a tool result that is an error, or whose text is a failure envelope, is not a paid result and is not recorded. `seedReceipts` puts a handoff's receipts in the document before a continuation's first request and keeps a receipt already held. A receipt holds the result's text (the text blocks, joined by a newline): another kind of block, an image for one, is not kept, and a repeat is answered with the text alone; a call that returned nothing is a receipt whose result reads `null`, and its repeat is answered, not dispatched. The document's kind, version and key are a stored format.
