`agentrun doctor` (`npx @parcha/agentrun doctor`) checks how this AgentRun is set up and prints each problem with what to change and a link to its documentation: the Node.js it runs on against the package's floor (the installer named as the fix), whether a server answers `/v2/health` for the data directory (`--data`, default `~/.agentrun`) and its version, the launchd or systemd service (installed, running, the `sudo loginctl enable-linger` line when lingering is off), whether a server on loopback can be opened from a remote session (an SSH tunnel, `tailscale serve --bg <port>` on your tailnet, never Funnel, or `--public-url` / `--allow-host`; a service installed with `--public-url` or `AGENTRUN_PUBLIC_URL` counts as served while it runs), whether the console's password is set (the fix names `agentrun open`, which opens the setup page with its code filled in or prints its link), whether a model is ready (Settings → Model keys, or a gateway through `AGENT_MODEL_BASE_URL`), which harnesses are ready (one that runs here with no default model is not, and its reason is said), the server's start-time switches where capabilities list them, and Docker for the boxes.
- It is read-only: it writes no file, starts and stops nothing, and sends only GET requests. It reads the server record `DIR/.server.json` as every CLI command does: a record that is not a private file of yours (a regular file you own, mode 0600, through no link), or whose `base_url` is not an http or https URL with no query, fragment, user or password (or has no positive `pid`), fails the Server check (exit 1); a record whose process has exited is stale (exit 3). Nothing is sent to the address either names. Capabilities are read with the server's own token from `DIR/.token`; no token, key or setup code is ever printed.
- Exit 0 when nothing failed (warnings allowed), 1 when a check failed (a refused server record included), 3 when no server answers for the data directory; `--json` prints the checks (`{exit, server, checks: [{id, status, summary, fix, docs}]}`) for agents. It takes no `--base-url`: it checks the AgentRun on this machine.
