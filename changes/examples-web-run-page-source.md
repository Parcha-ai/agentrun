The `examples/web` run page reads only through a `RunSource`, so the same page shows a live server's runs (`httpSource`) and a replay from static files (`staticSource`). `mountRunPage(root, source, { theme })` shows the ways to act and the live browser only when the source has them, and builds no absolute URL, so it works under any path; it draws light, dark or the system's (`auto`, the default) from `--ar-*` color tokens a host can override. `writeReplay` is the one writer of a replay's static layout, refusing ids and file paths a page could not ask for, a summary for another id and runs whose paths collide, and swapping the new replay in so a failed write leaves the old one whole, and `pack-page.mjs` writes the self-contained replay page with its Content-Security-Policy in a meta tag. A replay names a dollar figure only for a recording whose manifest says its providers are `real`: otherwise its cost is `null`, its usage rows count model requests with no amount, and the page's header shows no figure. The live server's page also lists the agent's saved sign-ins by site (`GET /agent`, never a ref) and says when a run started signed in; the live browser floats over the page, opening large while the run waits for the person; and once a run is not live its Browser tab plays back what its browser showed, recorded owner-only beside the run with nothing kept while the person signs in, and never part of a replay.
