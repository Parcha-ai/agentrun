The kernel has one registry of host tools, still unused until the cutover: read, write, edit, bash and the five background tools, each with main's name, words, schema and replay, in main's order. It also holds their limits, the tool gate's shell family, and the run's hands port. bash is bounded to the hands' ceiling, and the background tools run on the run's hands. The host gives read, write, edit and bash's own run, and a registry missing one of them is refused when it is built. With no computer, bash runs in the run's folder and is asked first, and the background tools are refused.
