The kernel has one registry of host tools, still unused until the cutover: read, write, edit, bash and the five background tools, each with main's name, words, schema and replay, in main's order. It also holds their limits, the tool gate's shell family, and the run's hands port. bash is bounded to the hands' ceiling. The background tools run on the computer's processes, eight at once, each started, counted and given its id in one step, and reach only processes they started; with no computer they are refused in words. An executor answers a failure in words apart from its output, so a timed-out bash keeps what it printed, and only an abort throws. The host gives read, write, edit and bash's own run, and a registry missing one of them is refused when it is built. With no computer, bash runs in the run's folder and is asked first.
