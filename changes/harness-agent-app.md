`agentApp(place, host, agent, options)` is the run app for one agent with no workflow: `AppOptions` for `pi-durable-disk run --app`, with the lead at the agent's thinking level (the node runner's rule: never `off`), its instructions, and exactly the tools it names, each installed and offered and no other. A name the host cannot offer is refused when `agentApp` is called, with the tool and what it needs (`the definition names the tool browser_read, and this host has no browser: set CHROME_PATH or both BROWSERBASE_API_KEY and BROWSERBASE_PROJECT_ID`); none is skipped.
- The tools come from one builder, `agentExtensions()`, which `compose()` now uses too, so a workflow's run and an agent's offer each tool the same way. `agentTools(place, host, options)` lists every name an agent may give, with the plane that registers it (`coding`, `host`, `vision`, `code`, `browser`), what it needs (`browser` or nothing) and, when the host cannot offer it, why (`unmet`).
- `read`, `write`, `edit` and `bash` are the coding tools (`bash` gets only `PATH`, `HOME`, `TMPDIR` and `LANG`); `code` is code mode, with vision installed underneath; the browser's tools, by their registered names, need a browser on the host and a run whose options do not say `browser: false`. With a browser tool, the browser's configuration is in the commit that creates the conversation, its sessions are reconciled before the run resumes and released before the instance lets the run go (`wake`).
- `hostFromEnv(place, { models, lead, env })` is a host for a run outside `demo()`: the caller's models, Jev only with `TYPESAFE_API_KEY` (priced at its list price), a browser only with both Browserbase keys or `CHROME_PATH`, and evidence, status and the record under the run's directory as `localHost` writes them. Its `runEffect` refuses: an agent run has no `call` node.
- `Host.lacks` names the planes a host does not have, each with what would give it one. On a host with no judge, `vision.judge` has no Jev port and says so as a typed miss. New runtime dependency: `@parcha/agentrun-jev`.
