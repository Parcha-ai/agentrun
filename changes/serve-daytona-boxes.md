An agent whose place is `{"mode": "sandbox", "box": "daytona"}` runs its `read`, `write`, `edit` and `bash` in a Daytona sandbox, on pi, claude-agent and codex alike, as a Docker place does. The server holds Daytona's key (`DAYTONA_API_KEY`, with `AGENTRUN_BOXES=daytona`) and gives it to nothing else: it makes the run's sandbox on the run's first such call, with its network blocked (`networkBlockAll`; a sandbox Daytona does not report blocked is deleted and the call fails), the fixed environment and the run's labels, and the run's process reaches that sandbox only through the server's box relay on loopback, which takes a run's call only with that run's own door token, adds the key to the calls a run's tools make of their own sandbox (a read of it, and its toolbox's programs and files), refuses every other call, and never follows a redirect (nor does pi-transport's Daytona client): a redirect would carry the key. Each run's door now takes a token of its own, `runs/<id>/door-token`, made at its first launch. A sandbox cannot bind the run's `work/`, so the server copies `work/` into it at `/run/agentrun/run/work` when it makes it, copies what changed back at each turn's end and once more before the run's end is recorded (with pi-transport's safe extractor: nothing outside `work/`, no link, a file the server changed meanwhile kept), and destroys it only once that last copy is whole: a copy that fails is tried again before the end is recorded, and one that stops for good (an archive the server cannot read, a limit it cannot pass) keeps the sandbox, said in the log, set to stop after 15 idle minutes (its disk kept, its compute stopped), woken and copied back by the next start. A read of the run's files waits for a copy its turn's end began, and a start pulls a run it finds waiting. What the server files in `work/` meanwhile (monid's long answers) is copied into the sandbox too. A start pulls, then destroys, the sandbox of a run that ended while its sandbox was left. In pi-transport, a Daytona box takes `network: "none"` (`networkBlockAll`, and `facts().network` is `none` only when Daytona reports it), and a workspace the sandbox's user may not create is made with `sudo -n`.
