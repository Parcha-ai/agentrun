A cache analyzer names each cache break. `analyzeCache(session)`, over a session read with `chain: true`, gives its cache hit rate (cache read over input, cache read and cache write) and each break: a turn whose cache read dropped more than 80% against the turn before it (never the first turn), with its time, the drop, the tokens it paid for again, what they cost above a cache read at the model's list prices, and its cause. The causes, tried in this order: `model` (another model than the turn before), `idle` (a gap past the cache's 5 minutes, or the hour when the last cache write was a 1h one), `compaction` (Claude Code's compact boundary or summary, Codex's `compacted`), `edited` (the prompt leaves the turn before's chain at an earlier message, found through hashes of the message chain), `sidechain` (a sidechain opens after a main-chain turn), else `unknown`.
- `readSession(locator, source, { chain: true })` keeps the session's `chain`: each record's id, its parent's and a 16-hex hash of its content, never the content. Claude Code's uuid chain and pi's id chain name an edit; a Codex rollout names no record to rewind to, so a Codex break is never `edited`. pi writes no compaction or sidechain record.
- `cacheHome(home)` analyzes every session parseHome totals of the sources that write a chain (`CACHE_SOURCES`: Claude Code, Codex, pi; another source is refused with a `RangeError`, as OpenCode's mirrored claude-agent requests would count twice), keyed the same way, and `node packages/import/dist/cli.js <home> --cache` prints it: a JSONL line per session, `{key, source, hitRate, breaks: [{turn, at, dropPct, rewritten, extraCost, cause}]}` (a subagent's break with its `subagent` number), then a totals line with the breaks and their extra cost by cause. Numbers and cause names only.
