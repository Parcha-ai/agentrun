A run that learns no longer keeps what the server tells it about learning, in a note or a skill, or a note beside a skill it keeps, which a grader could judge as planted and so drop the skill with it. A person's own instruction about learning is still theirs to keep. The run says it will keep what the person asked at the start of its reply, never after a sign-off they asked it to end with. When the grader keeps nothing, the run's learning names first the skill and the workflow draft it proposed, cut of the server's secrets each time it is read. A grader's answer the server cannot read is asked once more; when the second can't be read either, the run's learning is dropped and keeps that answer on the run's file, cut of the server's secrets and to 2,000 characters, and no read serves it. Upgrading: nothing to do.
