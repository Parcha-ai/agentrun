Redaction now reads text as a terminal shows it as well as with its controls dropped, so a held value split by an ANSI colour code, a title or hyperlink sequence (raw, 8-bit, or escaped in JSON, Python, percent-encoding or an HTML reference) or a backspace overstrike (of any character, one past U+FFFF too) is withheld; characters either side of such a control are normalized together, as a reader sees them, so a precomposed character split into its parts by one is still found. A NUL, a DEL or another control inside a sequence no longer ends it early, a sequence aborted by CAN or SUB shows as nothing, a printable character past ASCII inside a sequence no longer ends it, and a backspace strikes out the last character that takes a cell on screen (a space, a no-break space or a braille blank among them), never a control or a zero-width character. A call's read past its stop, and the read of a run too long to show, count what each of the matcher's views shows of the text, through that view's own decoding, join and terminal reading, so padding of such sequences however they are escaped, percent-encoded ones and sequences whose parts mix encodings included, never pushes the rest of a held value out of the read; padding that would make that read cost more than a fixed budget withholds the text instead. Coloured output with no held value is shown as before, and a held value coloured whole is still cut in place. Characters that show as a box or a blank (U+FFFE, U+FFF9-FFFB, the noncharacters U+FDD0-FDEF, private use characters, the braille blank and a lone surrogate) are dropped as a zero-width character is, while a surrogate pair stays. The MCP wire's and the computer keys' scrubbers withhold an answer that still holds a credential in such a form, and the source snapshot and the Git checkpoint block on one.
