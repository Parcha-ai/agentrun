Connect local Claude Code and Codex setups without copying their configuration or credentials. Native jobs preserve source permissions, uncertain dispatch and exact UTF-8 output, and can use checked notes and skills when learning is explicitly enabled. They honor typed input and output schemas, ask once more when the final JSON misses its schema, and can be cancelled while another job holds their source project. A stop or cancel received while recording final usage still owns the run's end. Native learning jobs record their agent execution path in the cost series while unknown dollar, token and request counts remain unknown in the API and console analytics. A failed or stalled terminal metrics read leaves cost and path unknown within the shared end-read bound, preserves the actual task outcome or person’s stop, and releases the source project without replaying the task. Native tool inputs and results (including credential-shaped property names and numbers), and final answers are redacted before entering the durable journal, including credentials already opened from the server’s sealed store. Codex uncached input excludes both reported cache components, and remains unknown when either split is missing. Preserve unmetered tool coverage alongside unknown native request counts. Already-admitted trigger messages wait for the person’s answer before delivery, and database fixtures release their connections and yield while removing injected write faults. Claude Desktop-only tools remain advisory and do not change a Code project’s launch fingerprint. Task usage remains unknown when a dispatched retry reports no counters, without mixing in separate reflection usage. Workflow node cleanup preserves the original stop after its owning invocation ends, including late attempts. Restart tests distinguish server recovery from a cut paid request whose charge remains unknown, and independent webhook fixtures keep their secret lifetimes isolated. Webhook test waiters recheck committed state when filesystem notifications arrive before a commit or are coalesced. Native prompts keep text and all typed input fields together, using the same fenced input formatter as managed runs. Native definitions reject removed tool-call settings, and old saved or queued revisions that still record a limit fail before dispatch until saved without that setting. Saved native instructions are passed as additive context from the run’s pinned revision, without rewriting native source policy or permissions. Learning uses the last bounded, redacted combined policy recorded before durable task dispatch; abandoned preparations cannot supply or hide the executed task’s policy. Native connections reject AgentRun model and thinking overrides at registration, save, restore and dispatch, with directions to configure the source CLI. Existing queued overrides fail before execution; explicit native connection management clears only obsolete ignored AgentRun fields without changing source configuration or silently deleting managed-agent settings.

Native connections also refuse managed tool permissions, tool or skill grants, unattended approval overrides, model tiers, different harnesses, computers or sandbox locations, pull-request checkouts and spending controls that their source CLI cannot honor. Empty grants and settings, asking by default, the source harness, runner location, no computer or checkout, zero cap and expected cap pricing remain compatible. Source-discovered models, skills and MCP servers remain source metadata. Legacy execution restrictions block restore and queued dispatch, stay intact on disconnect, and must be explicitly removed before reconnecting or verifying. Reconnecting a legacy binding with no stored harness restores its source harness for ordinary definition round trips.

Postgres deployment and data-root ownership tests stop their server and runner processes before dropping schemas, keeping teardown DDL from racing live background reads.

Native source MCP metadata never lists or pins tools from AgentRun's managed MCP registry, including when a legacy managed grant is refused. Runners require the server to install revision MCP and Monid metadata before opening an older store of the same schema version; only the server upgrades it.

Grades on completed native source runs remain recorded without reopening them into managed feedback rounds that the native runner cannot consume. Their CLI fixture's runtime-name selection is reviewed by the entry-point guard without changing symlinked Claude and Codex protocol selection.

Codex keeps intermediate messages visible as progress while only its last completed message supplies the final answer, output-schema check and reflection proposal, avoiding an extra task when the final JSON already meets its schema.

Native stops kill the source immediately and drain already reported tool and usage events before returning the original stop. Recording has a five-second bound; after it expires no later queued event starts, while any in-flight write remains subject to its claim fence.

Learning task snapshots retain unknown booking charges across a runner restart, so a priced retry cannot turn the interrupted task’s subtotal into a known cost. An already recorded task charge stays known when only its later learning request is cut.

Codex configurations that select custom model or developer instructions now mark learning evidence incomplete, including quoted TOML keys in user, project and selected profile files. Invalid, changed or unreadable configuration evidence also refuses automatic promotion before grading. Verification makes that limitation visible without disabling ordinary native tasks or changing their source configuration; saved instructions cannot clear the refusal. System Codex configuration is fingerprinted alongside user and project configuration. Older Codex snapshots without configuration inspection remain readable but cannot authorize new automatic learning; a new source run must capture the policy evidence.

Claude main-agent policy preserves user and current-directory settings precedence even when `CLAUDE_CONFIG_DIR` is deeper than or inside the project. Unrelated ancestor shared settings and user-global `settings.local.json` do not select the agent or change the launch fingerprint. Agent definitions are scoped by read-only repository-root metadata; project definitions override same-name global definitions and explicit selectors remain selected. Potential ancestor-local settings, worktree policy sources, or agent definitions whose scope or nested contents cannot be fully captured make automatic learning explicitly unavailable and the effective model unknown while ordinary native tasks remain available. Older Claude snapshots that did not preserve source precedence remain readable but cannot authorize new automatic learning.

Claude instruction snapshots detect potential imports before redaction and refuse automatic learning when imported policy was not captured. Known additional sources, including active AGENTS.md fallback, user instruction-file selectors, rules directories and managed policy, also refuse learning when their effective policy cannot be captured. Ambiguous multiline code examples and directories exceeding the bounded metadata inspection also refuse learning conservatively. Ordinary native tasks retain their source configuration and remain available. Older snapshots without the new source-coverage check, or without a recorded dispatch runtime, remain readable but cannot authorize new grading or promotion.

Normal server shutdown cancels a pending ChatGPT sign-in and releases its loopback callback listener without signing out or changing the saved credential.

Stop-withdrawal tests advance their store and runner retry clocks together, so a delayed observer cannot miss the first backoff. Wall-clock test deadlines and the production retry policy remain unchanged.
