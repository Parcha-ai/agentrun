Connect local Claude Code and Codex setups without copying their configuration or credentials. Native jobs preserve source permissions, uncertain dispatch and exact UTF-8 output, and can use checked notes and skills when learning is explicitly enabled. They honor typed input and output schemas, ask once more when the final JSON misses its schema, and can be cancelled while another job holds their source project. A stop or cancel received while recording final usage still owns the run's end. Native learning jobs record their agent execution path in the cost series while unknown dollar, token and request counts remain unknown in the API and console analytics. A failed or stalled terminal metrics read leaves cost and path unknown within the shared end-read bound, preserves the actual task outcome or person’s stop, and releases the source project without replaying the task. Native tool inputs and results (including credential-shaped property names and numbers), and final answers are redacted before entering the durable journal, including credentials already opened from the server’s sealed store. Codex uncached input excludes both reported cache components, and remains unknown when either split is missing. Preserve unmetered tool coverage alongside unknown native request counts. Already-admitted trigger messages wait for the person’s answer before delivery, and database fixtures release their connections and yield while removing injected write faults. Claude Desktop-only tools remain advisory and do not change a Code project’s launch fingerprint. Task usage remains unknown when a dispatched retry reports no counters, without mixing in separate reflection usage. Workflow node cleanup preserves the original stop after its owning invocation ends, including late attempts. Restart tests distinguish server recovery from a cut paid request whose charge remains unknown, and independent webhook fixtures keep their secret lifetimes isolated. Webhook test waiters recheck committed state when filesystem notifications arrive before a commit or are coalesced. Native prompts keep text and all typed input fields together, using the same fenced input formatter as managed runs. Native definitions reject removed tool-call settings, and old saved or queued revisions that still record a limit fail before dispatch until saved without that setting. Saved native instructions are passed as additive context from the run’s pinned revision, without rewriting native source policy or permissions. Learning uses the last bounded, redacted combined policy recorded before durable task dispatch; abandoned preparations cannot supply or hide the executed task’s policy. Native connections reject AgentRun model and thinking overrides at registration, save, restore and dispatch, with directions to configure the source CLI. Existing queued overrides fail before execution; explicit native connection management clears only obsolete ignored AgentRun fields without changing source configuration or silently deleting managed-agent settings.
