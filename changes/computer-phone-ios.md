The phone kind on a cloud iPhone (machine `ios`): `providerFor("phone-harness", { apiKey, platform: "ios", deviceId? })` starts the account's own iPhone, which the phone harness sets up per account on a flat subscription. It shares the Android provider's session and ledger layer (Idempotency-Key and recovery, the ledger, attach, list, release); only the device channel differs: `src/phone-control.ts` drives the session's HTTPS control API (`GET <url>/ops`, `POST <url>/op`). The control token goes only in the Authorization header, only to the API's own origin, and into no result or error, nor does the control URL's path. connect refuses an iPhone whose ops lack one a declared group needs, and a request whose grant expired is sent again once on the session's fresh grant. create waits, bounded by `readyMs`, for this provider's own released iPhone to end, and a 409 `profile_running` asks by the Idempotency-Key once and adopts the session a gateway's retry was refused for. An iPhone declares `screen`, `input.touch` and `apps`; `input.keys` and `apps.ui_tree` are coded behind undeclared groups until a live run on a real iPhone. `apps.terminate` is now its own group (Android declares it; an iPhone, whose control API cannot end an app, does not): `apps.launch-terminate` and `apps.install-launch` need it, and a new Core case, `apps.launch`, needs `apps` alone. A provider that answers `apps.terminate` now lists `apps.terminate` in its groups and hello, or its terminate cases skip as undeclared. Ledger entries of an iPhone carry `platform: "ios"`, and a provider sees only its own platform's. A frame is the capture's own pixels, and `frameMap` maps every point to the tap points the phone takes (Retina scale, the bounds' origin). A phone with neither files nor a tree is checked on Settings' screen (`touch.swipe`), and a case may skip as owed to groups the computer does not declare (`t.skip(reason, { undeclared })`), which the report shows and counts apart (`owed: true`). `ComputerCapabilities.maxComputers` (1 for an iPhone): the conformance runner ends its shared computer before a case that makes its own would pass it, and a case that holds more at once (`computers:N`: provider.attach, release-older, janitor) skips in words. The PNG reader moves to `src/png.ts`. The conformance module reads `COMPUTER_PHONE_HARNESS_DEVICE`.
