`agentrun-serve eval-template`: a fake MCP server's answer can match an argument by a regular expression, and a case can seed its runs' work folders. In a fixture's `when`, a value `{"$pattern": "<regex>"}` (that key alone) matches a call whose argument is a string the regex matches whole, anchored by the eval even when the pattern has no `^` or `$`, so a fixture answers keys made of a run's random stem (`{"submission_key": {"$pattern": "ns-[a-z0-9]{8}-voice-cold-open"}}`); every other value is still compared by equality. A `$pattern` that is no string, does not compile, or sits beside another key fails the case when it is read, naming the tool and the answer. A case's `case.yaml` takes `files`, a mapping of a path in the run's work folder to its text: the eval's runner writes each one at the run's claim, before its computer and its first turn, and leaves a file the folder already holds, so a case can start a run where an earlier one left off (a resume that reads `media/run-keys.json`). A path that is absolute, empty, has an empty, `.` or `..` segment, or lies under `inputs/`, and a text that is not a string, fail the case when it is read. Only the eval's own server honours `files`, so a case with it refuses `--server`.
