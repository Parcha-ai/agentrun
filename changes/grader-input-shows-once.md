An llm grader's input in `agentrun eval-template` now shows once what a long run's calls and files hold twice, before anything is cut. This applies only when the input is past its cap. A poll whose every `status` read "pending" is collapsed to its number, tool and status when the next call of that tool asked the same again and also read only "pending". The last such poll and every other answer stay whole. A value in a call's answer that equals one of its own arguments (200 characters or more) becomes a pointer to them, as when a submit's reply repeats the input it was sent. A value equal to a final file's whole content becomes a pointer to that file in `<files>`. The agent's skill copies under `.agents/skills/` are listed by name. Each kind is counted on a `Shown once` line in `<cuts>`. The cap rises from 120,000 to 176,000 characters (about 44k tokens), and the final files read for a grader rise with it. Before, a media run with a few hundred thousand characters of calls showed its graders neither a submit's request handles nor the middle of a page it fetched, and a grader failed a run that did what it checks. A run that fits is shown as before.
