New Python client `parcha-agentrun` in `python/`, on PyPI from 0.3.0 (`pip install parcha-agentrun`): a typed, synchronous client for a self-hosted AgentRun server on the standard library alone, Python 3.10 or newer. `AgentRun(base_url, api_key)`, defaulting to `AGENTRUN_BASE_URL` and `AGENTRUN_API_KEY`, has a method per operation the server offers, grouped as the CLI's commands are and named in snake_case (`client.runs.start(agent_id, body)`, `client.mcp_servers.save(name, body)`, `client.agents.list(limit=..., cursor=...)`), with `TypedDict` and `Literal` types from the server's OpenAPI document and a `py.typed` marker.
- It keeps every rule the TypeScript client keeps: one error class per outcome (`AgentRunRefused`, `AgentRunAuthError`, `AgentRunUnsupported`, `AgentRunUnreachable`, `AgentRunUsage`, `AgentRunTimeout`), no printed form of an error or of the client holding the key or the server's message text, a redirect followed only for a GET within the base URL's origin, retries only for a GET or a request with an `Idempotency-Key`, a secret body's values cut from the answer, and a `.` or `..` path argument refused before any request. `runs.wait(run_id, timeout=...)` long-polls and `runs.follow(run_id)` is a generator of the timeline's pages that resumes with `Last-Event-ID`. A download returns `bytes`, or a `StreamedResponse` with `stream=True`; an answer with an ETag returns `Tagged(body, etag)`. A method's `timeout=` bounds one try, its answer included, and is the way to cancel a call.
- `node scripts/generate-clients.mjs` writes `python/agentrun/_generated.py` from the same projection and resource map as the CLI's table and the TypeScript client, under the same hash, and `--check` covers it (`--python` names another file). CI runs the client's tests on Python 3.10 and 3.13, and pyright on `python/`. The `agentrun-cli` skill names both clients, and the source export carries `python/`.
- Fix: in `@parcha/agentrun-client`, a `runs.wait` whose timeout passes while a refusal's body is still coming throws `AgentRunTimeout` with the run as it is, not `AgentRunRefused`.
- Upgrading: nothing to change; nothing breaks, and the Python client is new.
