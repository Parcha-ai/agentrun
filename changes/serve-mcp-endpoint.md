A coding agent can set up AgentRun Server and drive it. `POST /v2/mcp` is an MCP endpoint (Streamable HTTP, one JSON-RPC message per POST, answered as JSON) whose tools list, read and create agents, start runs, read a run's status, result, timeline and files, and send a run a message. Each tool calls the matching `/v2` route in process with the caller's token, so it checks and answers exactly as that route does; a refusal is a tool result with `isError` holding the route's `error`. The endpoint takes the Bearer token only, never the page's session cookie, refuses a browser `Origin` other than the server's own (`403`), and refuses any method but POST (`405`). Claude Code connects with `claude mcp add --transport http`, and Codex with `codex mcp add --url ... --bearer-token-env-var`. `GET /llms.txt`, public, gives the API, the MCP endpoint and the CLI in brief, and the package ships `skills/agentrun-serve/SKILL.md`: installing and starting the server, the token, creating an agent, running it, reading its results, and connecting over MCP. The served OpenAPI document lists the endpoint as `callMcp` (`x-agentrun-serve: mcp/1`).
