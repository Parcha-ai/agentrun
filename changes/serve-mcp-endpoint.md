A coding agent can set up AgentRun Server and drive it. `POST /v2/mcp` is an MCP endpoint, Streamable HTTP in its simplest form: one JSON-RPC message per POST, answered as JSON, with no stream and no session. It has ten tools: `whoami`, `agents_list`, `agents_create`, `agents_revise`, `runs_start`, `runs_get` (with a waiting run's question and its console link), `runs_events`, `runs_files`, `runs_respond` and `runs_cancel`. Each calls the `/v2` routes in process with the caller's token, so it checks and answers as they do: the route's JSON is the result, and a refusal is a tool error holding the route's `error`. A run is started, then polled; no call is held open for one. The endpoint takes the Bearer token only, never the page's session cookie, refuses a browser `Origin` other than the server's own (`403`), and refuses any method but POST (`405`). `GET /v2/runs/{id}/timeline` takes `limit` (1 to 500 rows a page). `GET /llms.txt`, public, gives the server in brief, and the package ships `skills/agentrun-serve/SKILL.md` for a coding agent: check the server, the token, connect with `claude mcp add` or `codex mcp add`, create an agent, run it and answer it. The served OpenAPI document lists the endpoint as `callMcp` (`mcp/1`) and the timeline's `limit` as `timelinelimit/1`.
