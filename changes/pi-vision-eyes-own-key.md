The README shows how a provider key of your own reaches the eyes: `piAiEyes(model, { apiKey })` with a model from pi-ai's catalog (leave `apiKey` out and pi-ai reads the provider's own variable), or `eyesModel` through a pi-durable host's own `Models`. A table gives the key to set for Anthropic, OpenAI and Google, and `look.mjs` is a complete program that reads a picture a text-only lead cannot see, files the look's receipt and prints its price. `test/readme.test.mjs` runs it against an Anthropic Messages endpoint on this machine and checks that the key reaches the endpoint with the picture and is in no output and no receipt.
