An API-only server (`AGENTRUN_API_ONLY=1`) saves Composio MCP servers with the server's token and deletes the MCP servers that token saved, and never writes a secret doing it. A Composio server is saved with `"api_key_env": "COMPOSIO_API_KEY"` in place of `api_key`: the server keeps the variable's name, never its value, and reads it at each use (the save's calls to Composio, each run's connection, a delete's), as the server and each runner were started with it, so a new value takes effect when they start again. `COMPOSIO_API_KEY` is on the launcher's list of secrets: it reaches the server and each runner over the launcher's pipe, neither process's environment holds it, and no run is handed it. The runner sends it only as the MCP header of a Composio server the run is granted a tool of. The token saves over and deletes only a server the token saved: a save over one the owner saved (through the Composio save, or on the full server the generic save) or its delete, sealing a credential or not, is `403` to the token on every server, it stays as it was, and nothing is sent to Composio. An owner's save over a server the token saved makes it the owner's once it lands, so the token can no longer change or delete it; an owner's save that is refused (`412`) leaves the server the token's. The ownership is compared in the statement that writes or removes the row, so an owner's save that lands while the token's is under way wins, and the token's is `412`. Any other name is `422 invalid` under `api_key_env`, an unset or blank variable `422 missing`, and a run of a server whose variable is unset is refused before it starts (`409 agent_not_runnable`), naming it. That key is only ever sent to Composio's own origin, fixed in code: a server whose saved address is anywhere else is refused by name at a save, a refresh and a run's start, and nothing is sent. A Composio save's body names no address or headers (`url` or `headers` is `422 not_allowed`, on every server). The token lists the saved servers through `GET /settings/mcp-server-names` alone; it has no list or read of a server. `api_key` from the token stays `403`, as does the token's `api_key_env` on the full server, where the owner's signed-in session saves a Composio server either way.
