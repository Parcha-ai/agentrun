An API-only server (`AGENTRUN_API_ONLY=1`) saves Composio MCP servers and deletes MCP servers with the server's token, and never writes a secret doing it. A Composio server is saved with `"api_key_env": "COMPOSIO_API_KEY"` in place of `api_key`: the server keeps the variable's name, never its value, and reads it at each use (the save's calls to Composio, each run's connection, a delete's), so a new value is used from the next run. Any other name is `422 invalid` under `api_key_env`, an unset or blank variable `422 missing`, and a run of a server whose variable is unset is refused before it starts (`409 agent_not_runnable`), naming it. That key is only ever sent to Composio's own origin, fixed in code: a server whose saved address is anywhere else is refused by name at a save, a refresh and a run's start, and nothing is sent. A Composio save's body names no address or headers (`url` or `headers` is `422 not_allowed`, on every server). The token lists the saved servers through `GET /settings/mcp-server-names` alone; it has no list or read of a server, and no generic save. `api_key` from the token stays `403`, as does the token's `api_key_env` on the full server, where the owner's signed-in session saves a Composio server either way.
