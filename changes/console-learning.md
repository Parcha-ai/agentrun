The console shows what an agent learns. The agent page has a Learning tab: each note the agent wrote for itself, with its type, its body, the run it was learned in and, on a server that says what runs read, how many runs used it. A person edits a note in place (name, description and type as fields, the body as markdown; Ctrl or ⌘+Enter saves, Esc cancels), adds one, or retires one after a confirm. Each write names the version the person saw (the note's own ETag on its card), so a note changed in the meantime is never written over or retired unseen: the newest version loads, and the person's edit stays on screen to copy. Notes that were replaced or retired are listed under Earlier notes. Beside them are the learning switch, the latest runs that kept nothing with the reason in plain words, what the next run reads, and, from a server that has it, the before and after ("Since it learned (on 4 runs): answers in 12s instead of 18s · $0.03 est. instead of $0.11 est. a run"); until it has two runs on each side of the first note, one quiet line says so. An agent with no notes shows one sentence on what learning is, with the switch. The editor's Settings step has a "Learns from its runs" switch. It asks for no tool, since a run says what it learned in its answer. A run's header and its rows on the agent page and Mission Control say "Used 1 note" and "Learned 1 note", naming the notes on hover; the header's chips open the notes in the Learning tab. An ended run whose learning is still deciding is read again until it settles, and its timeline is read again each time its learning moves, so the timeline says what the header says. From a server that holds notes for the owner's OK (a note that changes what the agent trusts or skips), those notes sit at the top of the tab under "Waiting for your OK", each with Retire and, from a server that approves from the console, Approve, made on the card's version (a quiet line says when approving needs the owner's password sign-in, or comes in the next update), beside a line on what a run on the host can reach; a note from the person reads "From you", and a run that kept one says "1 note waits for your OK", linking to it. In the timeline, the end-of-run look-back is one step labelled Learning that says what it kept ("Looked back: kept 2 notes (Refund limit, Answer shape)", "Looked back: kept 1 note (Answer in tables); 1 note waits for your OK (Buy from PaperDepot24 first)", or "Looked back: nothing new to keep"), with what it did behind it; its message is no longer labelled as the person's. A run whose notes came back out of format says so: "Not kept: its notes weren't in the expected format."
