The console shows what an agent learns. The agent page has a Learning tab: each note the agent wrote for itself, with its type, its body, the run it was learned in and, on a server that says what runs read, how many runs used it. A person edits a note in place (name, description and type as fields, the body as markdown; Ctrl or ⌘+Enter saves, Esc cancels), adds one, or retires one after a confirm. Each write names the version that was read, so a note changed in the meantime is never written over: the newest version loads, and the person's edit stays on screen to copy. Notes that were replaced or retired are listed under Earlier notes. Beside them are the learning switch, the latest runs that kept nothing with the reason in plain words, what the next run reads, and, from a server that has it, the before and after ("Since it learned: run time 18s → 12s, cost $0.11 → $0.03, on 4 runs"). An agent with no notes shows one sentence on what learning is, with the switch. The editor's Settings step has a "Learns from its runs" switch, which says when the agent still needs the write tool. A run's header and its rows on the agent page and Mission Control say "Used 1 note" and "Learned 1 note", naming the notes on hover; the header's chips open the notes in the Learning tab. An ended run whose learning is still deciding is read again until it settles. In the timeline, the row that says how a run's learning ended is labelled Learning, and the message that starts the look back is no longer labelled as the person's.
