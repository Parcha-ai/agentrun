The `report` skill ships in the package (`skills/report/SKILL.md`, beside `look`, `transcribe` and `find` under `pi.skills`): how an agent ends a run with its own report, `report/index.html`, one script-free page that opens on the answer and its few key points, folds the routine detail and shows only the pictures that help, each with a caption that says why it matters. A document the run read is embedded as page images with every found mark outlined and labelled, linked both ways to its finding, and the PDF is linked at `#page=N`. A film is shown by its moments: one short clip for a window with that window's opening frame as its poster, and a frame, never the clip again, wherever the window comes back. When the question names a shape (minute by minute, page by page, a table) the answer is that shape, one cited row for each unit, and the page never states a name, place, time or number the run did not read. Every document or photo it cites, under about 3 MB, is copied into `report/` and cited by its name there, a film stays outside and is cited by its own name with its look, and nothing is ever written with `../`. Cites are links in the file's own address (`#page=N`, `#t=a,b`, `#xywh=percent:x,y,w,h` or `pixel:`), labelled with that number and carrying the key of the look they rest on in `data-look`. Pictures and clips are re-encoded without metadata and held to a size budget, and the page loads nothing from the network. The skill is six pieces of code for code mode and a check to run before the agent stops. `test/binaries/report-skill.test.mjs` runs the pieces on a film, a PDF and a photo the test builds, checks the page and its files, and shows the check refusing each fault.
