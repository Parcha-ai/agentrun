A browser call's charge reads on its own timeline row, as "· $0.0018" beside the call's label, or "· so far $0.001, 1 not priced" when a charge has no price. Before, it was a separate "Tool cost" row. A charge booked later, such as the session's release after the answer, updates that row in place. The run's own usage row is unchanged.
