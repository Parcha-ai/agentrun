SDK runs accept externally executed agents through `sdk: {runtime: "external", platform: "OpenClaw"}`. Use `"Capy"` or another platform label without adding a runtime. The required label is 1–80 Unicode characters with no leading or trailing whitespace, control characters or unpaired UTF-16 surrogates; it is preserved in the console and on each recorded run. Registration and run start must name the same runtime and platform. Other SDK runtimes reject `platform`. See [Report runs from an external platform](../docs/tutorials/platform-sdk-runs.md).
Execution stays on the platform: managed launch, stop, cancel and follow-up requests are refused. External sources receive the owner's corrections when learning is on, with no workflows. Starts carrying `workflow_tools` or `workflow_adapters` are refused (422) before recording a run. `BackendLearningClient`, imported from `@parcha/agentrun-client/learning`, accepts the external binding and refuses a `workflows` bridge before any request. Existing Claude Agent SDK, Codex SDK and eve integrations retain their behavior.
The generated TypeScript `StartSdkRunBody` is now a union. Consumers that extend it with an interface or index its workflow fields must use a type intersection or select the SDK branch; the [client README](../packages/client/README.md#learning-for-existing-backend-sdk-agents) describes the migration. `BackendLearningStart` remains extensible, and existing Python TypedDict constructors and CLI flags are preserved.
