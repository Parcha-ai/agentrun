pi-durable-agent's tests drop the cases another test already runs on the same path, the checks that only read source text, and the waits on a wall clock. Gone, with what still proves each: the agent store's carry-back and failed-seed cases (the run-half tests make the same calls and check more, the cost round trip and the refused second carry back included), the cross-agent join case (the store test that refuses a revision of another agent through `startRun` runs the same join), the free `startRun` case (the home's own run tests), the check that one internal name is absent, the import-closure source walk of the package root (the resolve-hook test that an agentic-only store loads neither the DSL nor agentrun-pi), a crash-after-commit import case (now a row of the "a commit is terminal" test, with recovery not stopped), a test of a fixture's own side-file branch (side files stay refused by the pack tests), the nested-call scrub case (the URL-scrub test now has a nested call whose args hold a URL), the package-manifest case (the installed-package check), the bin's "neither a store nor a home" case (the bin test now checks the exact message and that it names no folder), and two house-style and call-shape source greps. `headOf`, `signature` and `lineDiff` are no longer exported from their internal modules: `homeRevision` now also refuses an infinite `next_seq` and accepts 2^53 - 1, the snapshot test now proves a commit still in an open writer's log makes a new snapshot, and the long-prompt diff tests read the diff through the store's API. The cross-process lock test waits on the other process's release and two writes to a free home instead of a 700 ms timer, the abort test checks a new connection is refused instead of sleeping 50 ms, and the stats and pax-header tests no longer bound the wall clock. The README test reads the five entry points' declarations with one TypeScript program instead of five, about 9 seconds less in CI.
