A run that sends no model key (held because its model can't run, on a `--faux` start, or pinned to the faux model) now opens no saved key it never sends for anything it lays, hands on or sends, including runs that run inside the runner (the run's redactor still loads the server's saved secrets, so an echo of one is cut from its records). On a `--faux` start, a subagent, learned-workflow or grader tier no longer opens any saved key, and neither does an SDK run's compile turn; that turn is also no longer skipped for want of a gateway key, since the faux model sends none. A run's own model key handed at its start is never read out of its launch, held or sent for a held run or one on a `--faux` start. A run pinned to the faux model keeps it, and a workflow pinned to it is still laid its saved model keys: its subagent tiers, learned workflows and model nodes run on the runner's models. The check that a server holds a gateway key now reads that key alone. A run with decision nodes opens the gateway's key for them only when its decisions would use it. A run's Composio connected-account check now asks Composio nothing for a blank user, which it treats as having no account.
