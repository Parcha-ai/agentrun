A plain `npx @parcha/agentrun` runs a Claude Code agent with nothing else installed: Claude Code installs itself on first use. AgentRun still never ships the Claude Agent SDK. The first run on claude-agent, or the first agent saved on it, installs the version AgentRun pins (`@anthropic-ai/claude-agent-sdk@0.3.286`) from npm into `<data>/harnesses`, with the npm that runs the server, no key of the server's in npm's environment and no install script. The install is pinned by a lock the server ships (`harnesses/claude-agent/`, the package.json and npm's lock for it, every package of the tree by sha512, which `npm ci` holds each tarball to from whichever registry npm is configured for), and it lands whole or not at all: npm installs into a fresh directory, the result is checked there, then renamed into place and made read-only. Every launch of a claude-agent run waits for that install first (its start, a recovery after a restart, a relaunch, a wake), so no run starts on a missing SDK, and a run a crash left waiting is installed for and resumed by the next server. A run waiting for the install keeps its place under `max_concurrent_runs` and the memory limit until it launches, and gives it back at once if it is cancelled or fails. It is one install at a time: every run that needs it waits for that one, its ready time counted from the install's end, and shows a `phase` row, `Installing Claude Code (first use)…`, while it does. Each claude-agent run then loads the SDK, its CLI and the MCP library from `<data>/harnesses` and nowhere else, never a copy beside the server or a global one. Until it is installed, `GET /v2/capabilities` lists claude-agent with `installs: "on_first_use"`. Each piece loads only from its own package inside `<data>/harnesses`, never from a `node_modules` above it, and a tree that is not whole is installed again; a server that stops mid-install stops its npm. When npm fails, the run fails and its error names the command that installs it by hand, the same locked install: the shipped package.json and lock copied into a fresh `<data>/harnesses.new`, `npm ci --ignore-scripts` there, then that directory put in place of `<data>/harnesses`. claude-agent's npx hint (`npx -p … -p @anthropic-ai/claude-agent-sdk@0.3.286 …`) is gone, and codex's and OpenCode's npx lines no longer name the SDK. `@parcha/agentrun-harness-claude` takes the MCP library a host loaded (`mcp`, passed to its tool server) and exports `claudeAgentPlatform()`, the suffix of the SDK's CLI package for this machine.
Upgrading: Claude Code installs itself on first use.
