The console has a Free page (`#/free`) that shows what runs for $0 on the server. It lists the free models, with the ones on this machine's Ollama first and each with its context size. A free catalog model also shows the server's request limit a run. It shows what `web_search` and `web_fetch` go through now, in the server's own `why` words. It lists the templates that run on a free model and ask for nothing else that costs money (no key, no MCP toolkit, no browser tool, and no computer but this server's own Docker sandbox), whatever tags their package gives them, each with "Use free", which opens the template's Apply screen with the agent on the free default model of the harness Apply makes it on (apply's `overrides.model`). Where that harness has no free model, "Use free" is off and the card says so. With no local model, the page says so and shows the Free local model card, which pulls the model that fits this machine through its own Ollama. Once a pull there ends, "Use free" opens Apply on that pulled model, though the server's default is another free model.
A completed run that cost $0 on free models shows a receipt on its page. The receipt gives the model, why the run was free (a local model on Ollama, a free model with its request limit a run, or both), the requests and tokens, each tool's calls and what they went through, the run's time and its $0 cost. For a run whose trace was cut at its cap, each tool's count reads "at least" and the receipt says how many rows it did not read. A failed or cancelled run, a run whose cost is unknown, and one that cost money show none. Nor does a run whose usage has anything unpriced or unbooked beside its free model requests: a usage total that is not exactly $0 (browser time with no booked charge), a line with no figure (computer time no price was set for), MCP calls no price meters, or computer time no claim held. GET /v2/runs/{id}/usage reads a `compute_time` line's `unheld_quantity` as 0 on a provider that bills nothing (Docker), so a free run on Docker keeps its receipt.
