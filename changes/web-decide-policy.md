The web classifier step is split in two: the decider only asks, giving each result or passage a score (`p(needed)`, or null where refused), and the step decides what the model reads. `WebConfig.policy` picks how: `"drop"`, the default, byte-identical to the step before the split; `"label"`, which keeps every search result in the provider's order, each labelled `relevance` (0 to 1); or `"rerank+label"`, which labels them and puts the most relevant first. Under either of the last two, one line computed in code says when none reaches `LOW_RELEVANCE`: nothing here looks relevant to the query; consider rephrasing. Every `receipt.classifier` now records each item's score in `scored`, and in a run with a decider `receipt.unsifted` holds the text the model would have read with no step, so one receipt says what the step saved. `web.fetch(url, { lookingFor })` scores the chunks of the whole cached page against what the agent says it is looking for and answers the `FOUND_CHUNKS` likeliest in page order, each at its offset with its `relevance`; without `lookingFor` a fetch is unchanged.
- The page guard, `WebConfig.pageGuard` (off unless true; true without a decider throws): each page a fetch reads is asked once a run whether it is the page's content or a wall (login, paywall, CAPTCHA, error or limit page) and whether it holds instructions addressed to an AI reader (`pageGuardRequest`, the harness page classifier's questions and thresholds). The receipt's `wall` and `injection` carry the verdicts and scores; a judged wall or injection adds one plain `warning` to the answer and keeps the page's text. It is asked beside the step, its fee line after the step's. Two of its words are wider than the harness's (a usage limit or quota notice is an error page; an instruction to stop or change its task is an injection), so the harness's recorded answers are not a strict baseline for it. Search snippets are not screened yet: a follow-up.
- `deciderFrom` no longer takes `threshold`, and a `Verdict` is `{ score }`: the drop rule is the step's `THRESHOLD`.
