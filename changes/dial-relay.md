A provider whose machines dial the server (Fly Machines, Cloudflare, and E2B, Daytona or Modal set to dial) now works under a runner in a process of its own, the image's default `server-and-runner` included. The server stays the one public address: a machine dials its `/v2/computers/attach` as before, and the server relays the socket to the runner that made the machine. Give the runner the server's public address (`AGENTRUN_PUBLIC_URL`, as the server reads it; the image passes the environment to both); across hosts, give it `AGENTRUN_RUNNER_LIVE_HOST` and list that host in the server's `AGENTRUN_RUNNER_HOSTS`, as for a run's live computer view. Nothing changes on the machine.
The runner mints each machine's token into the shared store with its name and incarnation on the token's row, and serves its own attach hub on a private listener (loopback beside its server, its live host across hosts). The server opens a socket to that listener with a proof under the seal key that binds the token, the runner, its incarnation and a time within 10 seconds, taken once: the listener answers nothing without it, and takes only a token its own runner minted in this incarnation. The relayed socket keeps the server's attach limits (frame size, binary refusal, idle timeout), and a close on either side closes the other. A dial whose runner is gone, does not answer or restarted since is answered 503 in words that name its run, `a dial for run <run> (machine <machine>)`, and never its token; the server's log line says the same, and the run makes a new machine at its next claim. A hosted provider's create names the machine's run in its token's mint (`MachineMint.run`, from the create's `agentrun.run` label), and the token's row keeps it.
With such a runner, each dial provider's `runs_refused` in `GET /v2/computers` is null and its test reads the vendor's account again. A runner with no public address relays nothing, and the row, the test and the runner's create keep their words.
The SQLite store goes to version 13 at the server's first start (from 11 or 12), and Postgres takes migration 0018 (`minted_tokens.runner`, `.incarnation` and `.run`, and `runner_relays`). A runner refuses a version 12 store until the server has upgraded it.
