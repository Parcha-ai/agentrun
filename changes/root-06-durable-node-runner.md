`@parcha/agentrun-pi/durable` runs a workflow's LLM nodes on pi-durable. `nodeRunner(host)` returns one extension to install before the Harness opens, and `on(scope)` gives the `runNode` that `withRecovery(driver, { runNode }, { durableNodes: true })` calls once per attempt and the `closeStepSession` that `openRecovery` takes. A host passes `agent()` and, as it needs them, `stance`, `record`, `verify`, `onNodeOpen`, `init`, `submit`, `digest` and `maxAttempts`. One attempt is one conversation, found again after a crash: an attempt that already delivered makes no request, a turn that committed is never requested again, and nothing of a resumed node reaches a model before the host's `onNodeOpen` ran. `legacy(entry)` gives a conversation an older build opened its extension back under that build's name.
- The record core the node's `submit` tool is built from is exported with it. `deliver(contract, store, args)` decides one call over a small store interface: transport repair, the file envelope under a host-named key, the delivery attempts, one feedback round of a second reading, and the model-facing texts. `lintRecordSchema` reports what an author should fix in a record schema, for a host or a validator: a root that admits no object, and a schema that declares its fields and requires one outside them. `recordTool`, `recordNudge` and `workspaceRecordFile` put it on a pi-durable conversation, and `runNodeAttempt(scope, attempt)` is the kernel under the runner (`taskScope`, `hostScope`).
- Four document kinds. `agentrun.record` (`{ record, attempts }`) and `agentrun.gate` (`{ bounced, disagreements }`) are conversation documents, and `agentrun.nodes` is a session document family keyed by the attempt's session id (`conversation`, `digest`, `startedMs`, `closed`). `agentrun.node` is new: a conversation document with the node's system text, label, schema and file key. It is additive, and a conversation an older build opened gets one when the runner first reaches it.
- A node that delivers no record throws `NodeFailure` (`code: "NODE_NOT_DELIVERED"`). `final: true` says a second attempt would spend the same again: the delivery attempts are spent, the model did not answer past pi's retries (pi's reason and detail are on `unanswered`), or the schema is one no `submit` call can satisfy (`lintRecordRoot`: it is no JSON Schema object, or its root type admits no object), which is refused before any conversation exists. A schema that requires a field outside its `properties` is not refused: the tool's parameters are open and the node's task carries the schema, so a model can deliver on it. `final: false` says the node's run ended with no record and attempts left, so a driver may admit a second attempt, a new conversation. An attempt found under another binding digest is refused with `NodeBindingMismatch` (`code: "NODE_BINDING_MISMATCH"`). A pause rethrows the run's stop and leaves the conversation for the attempt's next entry; any other stop aborts the conversation's work. A host whose `onNodeOpen` throws fails the node's call with that error and releases nothing: what pi resumed of the node waits for the attempt's next entry, or ends with the Harness's close.
- Two limits of the attempt count, each pinned by a test. The nudge that spends the last attempt still continues the run, so a run can take one request more than its attempts and the stored count can read one past the limit. A rejection cut by a crash after its commit is decided and counted again when the call replays, so a crash there costs the node one attempt.
- `spec/lean/AgentRunEnvelope/Gate.lean` models the gate's delivery (attempts, the one feedback round, termination), with an audit that fails when its list of theorems changes; `lake build` builds it by default.
