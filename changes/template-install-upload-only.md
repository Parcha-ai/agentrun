`agentrun template install SOURCE` now works on a server that takes uploads only. Such a server refuses a GitHub source: serve in its API-only profile (422 `input_invalid`, field `source`, reason `not_allowed`) or a server that answers 422 `files_only`. Before, the command printed that refusal and stopped. Now it reads the package from GitHub itself, anonymously, at the commit the ref points to (serve's own reader, exported as `@parcha/agentrun-serve/template-source`). It then uploads the package's files the way `agentrun deploy DIR` sends a folder's (`{files}`), and `--dry-run` is passed through. An upload keeps no publisher, so on that path every install needs `--trust` unless it is a dry run, and without it nothing is read. The output's `sha` is the commit that was read, `source` is pinned to it, `publisher` is null, and stderr says the command read GitHub itself. Every other answer is unchanged: a server that takes the source still gets one request, keeps the publisher's trust and pins the commit itself.
