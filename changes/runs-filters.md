`GET /v2/runs` takes `from`, `to` and `model`, for any run, whether made here or imported. `from` and `to` are RFC 3339 date-times with their zone (`2026-11-01T00:00:00Z`, or an offset such as `+01:00`). They list the runs started in [from, to): a run that started exactly at `from` is in, and one that started exactly at `to` is out. Either one can be given alone. An imported run starts when its session did. `model` lists the runs that used that model, named as a run's metrics name it, `provider/model` (`anthropic/claude-sonnet-5`, `openai/gpt-5`). The server reads no time zone; the console turns its own dates into instants. The console's runs list keeps all three in the address (`#/runs?from=...&to=...&model=...`, each with a button that clears it). The CLI, the TypeScript client and the Python client send them as `--from`/`--to`/`--model`, `from`/`to`/`model` and `from_=`/`to=`/`model=`. A window or a model that no run has lists none. These are 400: a `from` after `to`, a value that is not a date-time with its zone, an empty model, and a second value for any of the three.
