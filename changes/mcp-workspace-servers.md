On an API-only server, a request in a workspace (`AgentRun-Workspace`) is served the MCP servers' list, names, read, preview (of its own server, or an address at the operator's MCP origins), save, Composio save, refresh and delete, and reaches its workspace's own servers alone: another workspace's server of a name reads as a name never saved, a save of the name makes the workspace's own, and its agents reach their own server of a name before the install's shared one. A workspace's server is kept as `<workspace>/<name>`, with no schema change, and its sealed credential is bound to that row. A save in a workspace is of an address at the operator's MCP origins: `per_run`, or `headers` or `bearer`, whose credential is sealed in the workspace's own row and sent by its own agents' runs alone; or a per-run Composio save with `api_key_env` (a `user_id` of its own or an `auth_config_id` is 422 `not_allowed`). The token with no header still writes no credential. A workspace's sealed server at an origin taken off `AGENTRUN_API_ONLY_MCP_ORIGINS` can't be used, and a run already going stops sending its credential at its next call, as with a token's `per_run` server.
