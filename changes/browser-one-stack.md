The browser tool has one stack: whether the agent's computer is a browser or the tool plane picks the vendor, every session is a browser computer of the computer registry's providers, made at the tool's call under the run's labels, and pi-browser's raw-CDP driver (`cdpDriver()`) drives it. Stagehand drives no run's browser now. Breaking: Browserbase and Kernel browsers now refuse run code and file uploads (browser_upload), and their snapshot is the raw-CDP list; every browser computer uses one driver. Breaking: pi-browser's `./providers/browserbase` and `./providers/kernel` exports and its `@browserbasehq/sdk` peer dependency are gone (a hosted browser is a browser computer provider of `@parcha/agentrun-computer`), and so are Browserbase's and Kernel's `create(spec, { settings })` vendor-field bag and its `BrowserbaseSessionSettings` and `KernelBrowserSettings` types (put a session's options in `spec.browser`).
- `@parcha/agentrun-computer`: a browser's own options ride the spec, `spec.browser` (`viewport`, `profile: { pointer, save }`, `stealth`, `headless`), and `capabilities().browser` declares what a provider's sessions offer (`timeout`, `profiles: { settleMs }`, `stealth`, `headless`, `downloads: { path }`). `check()` refuses an option the provider does not declare, in words. Browserbase and Kernel gain the optional `profiles { create, remove }` member, and Browserbase `downloads { list, read }`. Local Chrome declares `{ timeout: "wall-clock" }` and opens its window at the spec's viewport.
- `@parcha/pi-browser`: `ProviderCaps` is `profiles`, `sharedBrowser`, `settings`, `fixedSession` and `navigationAllow`; the session vault keeps a local Chrome's sessions alone. `cdpCall` is exported from the package root.
- agentrun-serve: on Browserbase and Kernel, the browser tool's `run` now takes actions only, as it does on Local Chrome (code is refused in words, and navigation is a `goto` action), its `snapshot` is the raw-CDP driver's, and `browser_upload` is refused (the driver sets no file input). A session carries the run's labels and its custody tag, as an agent's browser computer's does.
