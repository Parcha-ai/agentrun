The learning docs (the README's Learning section, the server's, and its learning folder's contract) now describe learning as it works today. A proposal's checks leave out an item that breaks a rule of its own and keep the rest; a secret, a hidden character, a path outside the folder or a deletion still drops the whole answer. One front-matter reader decides a learned skill's and workflow's status. Past the budget, a run gets the notes that bear on it. A workflow draft is asked for once a skill has served 3 runs, and it is dry-run before it is kept. A run that only ran a learned workflow skips its end-of-run turn. The runner opens a learned workflow's decision keys. The grader drops account numbers and planted rules, and its Risky question reads one way on every model. CLI runs read `reflecting`. The learning bench is described. A short list says what is coming.
