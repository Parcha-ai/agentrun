A server with no model can pull a free local model in one click. The console's first screen shows a "Free local model" card beside the model key card: this machine in one line (system, memory, GPU, Ollama version), the model recommended for it and why, and a Pull button with a progress bar. Once the pull ends the model is in the picker with no restart, and the first screen's templates run on it: a template's agent made earlier on another model is left as it is, and a new one is made on the pulled model. A progress read that fails is followed by another, so the card still reaches ready.
- `GET /settings/local-model` reads the machine (platform, arch, total memory, Apple silicon or the first NVIDIA GPU `nvidia-smi` names), whether the Ollama here answers `/api/version` and its version, the recommendation, and the pull here with its progress. `POST /settings/local-model/pull` with `{ "tag": "<tag>" }` starts a pull through that Ollama's `/api/pull`. Both take the owner's session alone, never the API token.
- The recommendation: `inkling-2-mini` on Apple silicon with Ollama 0.40.17 or later; everyone else gets `qwen3:8b`, or `qwen3:4b` where memory is short, or none with what to do instead. Each tag's memory floor is named in the why. Apple silicon on an older Ollama is told to update it for `inkling-2-mini`. With no Ollama running, the card says where to install it. A tag already pulled needs no pull.
- A pull takes only a tag the recommendation can name (422 for any other), runs only on one owner's own server on their own machine, never under the faux model or a model gateway, and never into an Ollama that `OLLAMA_HOST` puts on another machine (403 in words), and runs one at a time (409 `local_model_pulling`). The server logs its start, end and failure with the tag, the bytes and the milliseconds alone.
- With `OLLAMA_HOST` on another machine, the server recommends nothing: it reads only its own memory and GPU, so it says to pull where that Ollama runs.
- The card stays up from a pull's start until its Done, on the first screen and on `#/free`, so a capabilities read that lists the model first never takes it down before the pulled tag is picked.
- Under the faux model or a model gateway this server asks no Ollama: the read surface says so (`ollama.asked` false), and the card shows only why no pull is made here.
