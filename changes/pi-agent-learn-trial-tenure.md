`workflowAdmitter({ tenure })`: a live trial keeps its tenure while runs are in flight. The host says where each run started (the main commit it was prepared from, and its place in the start order) and which runs are still in flight: every run that has not ended, however it ended (a run that crashed, was aborted or deadline-killed, or failed on its infrastructure leaves `inFlight()` at its end, without reaching curate). Opt-in: without `tenure` nothing changes. A new revision is held, and the live trial kept, when the run that saved it started before the trial was live, or while a run that started with the trial live, and before it, is still in flight. A champion is never held, each hold ends as the earlier runs report back (a trial no run uses cannot keep its name), and with no run in flight nothing changes. Without it, at 12 runs in flight a run that escalated and saved a fix could retire the trial before the runs that ran it cleanly reported, and no trial was ever promoted.
