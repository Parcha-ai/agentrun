After an active agent's latest run completes successfully, its console page offers a production onboarding call and a separate AgentRun Cloud sign-in link. It confirms the full run result first and stays hidden if that read fails or the answer is invalid. Both links open without sending local agent details, prompts, configuration or the referring URL. Local Run and Edit stay available; no Cloud account is required to keep using this server.
