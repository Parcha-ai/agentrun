The Learning tab shows the owner's bill: run after run, what the agent has cost with learning (every run that does a job, its look-back, grade, audit shadow run and its share of its workflow revision's compile and check, booked dollars only), cumulative, against the agent doing all of it (the mean of its own runs before its first run on a served path, times the runs), with a break-even marker where the bill falls to that line and stays, or "not yet" with the gap. Under it, the audit line (agreement over the hold window and all time, each hold at the run the server placed it on) and the serving workflow's nodes with their tiers, code checks and the check it was promoted on.
  - `GET /agents/{id}/learning/cost` has `bill`: its points, the baseline, the first served run, `break_even` or `gap_usd` (spend booked after the last point included), the runs withheld, each revision's compile and check spend as its next `compile_after` served runs carry it, what no run carries (`unattributed_usd`: the booked total less every run's all-in) and each hold at its run (`holds`).
  - `GET /agents/{id}/learning/promotions` has each serving workflow's `champion`: its nodes with their tiers and code checks and the check it was promoted on, read by the champion's recorded digest and commit.
  - `GET /runs/{id}` has `path`, and its `cost.usd` is the job's own: `cost.learning_usd` is what learning spent for the run (its look-back, a compile turn left out, its grade, its audit's shadow run, its share of its revision's compile and check) and `cost.all_in_usd` the two. A compile turn is its revision's; one whose drafts all failed is in the bill's `unattributed_usd`. Every run's `all_in_usd` plus `unattributed_usd` is the bill's total.
  - A shadow run is in no run list, sends no webhook and is no run of `GET /stats` or the analytics' counts; its cost stays in their dollars, on the day and in the groups of the run it audits.
  - The server has `deleteLearning`, the learning half of an agent's delete: the learning folder (its git history and audits.jsonl) and the agent's promotion, grade and eval records, refused while learning work is in flight, and safe to call again after a crash.
  - Upgrading: `cost.usd` on `GET /runs/{id}` is now the job's own spend, so a run's look-back and compile spend move to `cost.learning_usd` (a compile turn's to the runs its revision serves), as does a served run's audit shadow cost. Read `cost.all_in_usd` for what learning added to the run.
