`@parcha/pi-browser`: `use_website` children take turns when the provider in use shares one browser (a provider says so with the new `sharedBrowser` cap, which `cdpProvider` sets on an endpoint), and a durable child keeps its turn until it has read its report and released its browser. The first call after a release says so first and carries `previous_session`, and a read of a fresh `about:blank` browser says it is fresh instead of a wall. An attach waits for an init an earlier attach left running in Stagehand's extension, instead of failing with "Stagehand initialization is already in progress". A page snapshot or screenshot the browser never answers fails at its deadline as a dropped connection, and a read that hangs again after a working reconnect is told as a stuck page, with `browser_relaunch` as the way out. The coding agent returns the typed `person_driving` result for a refused release or relaunch. A saved lease's private TMPDIR is found after a provider restart. `copyProfile` no longer ends the host process when a file vanishes between its listing and its copy. A blank optional property means not given, not an intent to refuse; a screenshot's question travels with the capture; a classified failure names the browser provider, not Browserbase; a conversation's close evicts its repeat guard and idle entry; an upload that throws is named as the upload.
