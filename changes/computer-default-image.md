`PROVIDERS` entries carry `defaultImage`: the image a computer of each setting kind starts from when its setting names none, so serve no longer keeps its own table. Each value is the constant its provider module owns: `DAYTONA_DEFAULT_SNAPSHOT` and `BROWSER_IMAGE` as before, and new named constants in the E2B, Orgo, Modal and phone modules where only a literal stood (their refusal words and conformance images now use them too). A kind with no entry has no default, and the caller refuses the setting in words. Docker has none, since serve builds its image.
