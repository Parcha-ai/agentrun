Add Agent Factory, a kanban view of sessions reported to the server: waiting, working, needing attention, or with unknown source activity. Cards link to the existing run viewer and to GitHub work established by launch or trigger provenance. Reported active child conversations stay visible, SDK sessions and connected CLI sessions are labeled observed, with no stop or cancel offered, and ended failures and escalations needing attention appear separately. The same sessions also read as a list grouped by state, one row each, where a state's heading folds its rows away: a List and Cards switch beside the totals picks the view, and the browser keeps the pick.

Active and review scopes on the runs API filter before keyset pagination, including archived active executions and an audit's shadow run while it runs, while excluding imported history. A scoped page reads each run from the listing its row keeps, built once per change of the run as the runs list's items are, so a refresh builds no view of a run that has not changed; its journal is read again only to say who drives a desktop or phone that is up, or where a computer held for its owner stands. A GitHub link is what the server saved of the delivery that fired the run, so an example payload in a trigger's instructions is never taken for the event. The console refreshes bounded pages every 10 seconds, says beside Refresh when the sessions were last read, exposes remaining coverage, and keeps last-known cards visibly stale when a refresh fails. Its Control filter offers Managed and Observed whichever the loaded sessions have, and its top bar stays while the sessions scroll under it. This visibility layer does not schedule work, grant new controls, or infer verification or merge state.
