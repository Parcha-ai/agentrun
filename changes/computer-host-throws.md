---
packages: @parcha/agentrun-computer
kind: breaking
---
A vendor on the shared machine-host adapter writes plain calls: every `MachineHost` member answers its value or throws, never a `Result`. The adapter reads a thrown error's code from a `HostError(code, message)` (new in `dist/host.js`), else through the host's optional `errorCode`, else `"vendor"`. A host written against the old shape must drop its `ok(...)` and `{ ok: false, error }` answers and throw instead.
- Breaking: `exec(id, argv, ctx)` takes no `{ stdin }` flag. stdin is always open, and the adapter calls `end()` at once for a command it gives no input. A host's `exec` must keep stdin open until `end()`.
- Breaking: `Machine` is `{ id, labels, state, endsAt? }`, plus `createdAt`, `gpu` and `why` where a host reports them. `state` is `starting`, `running`, `stopped` or `gone` (`stopping`, `going` and `failed` are gone; a failed machine is `gone` with its `why`). `network`, `image`, `size`, `drift` and `timerMoved` are gone, and the vendor read-backs that filled them (E2B's template, lifecycle and end; Agent37's template, type, region and auto-sleep; Daytona's snapshot, intervals, TTL, class, public port, KVM, volumes and linked sandbox) are deleted. The network is probed from inside on every hosted vendor, so `capabilities().networkReadBack` is now `false` for E2B, Modal, Daytona and Agent37.
- Breaking: `MachineHost.prepare` and `MachineHost.stop`, and `HostFacts.networkReadBack`, `release` and `stopDeletes`, are gone. A hosted computer is deleted, never stopped and kept: every hosted provider's `capabilities().release` is `["delete"]`, and `release(ref, "stop")` is refused as `unsupported` with no vendor call. Daytona loses `release(ref, "stop")` and `capabilities().stopDeletes`; a caller that stopped a Daytona computer deletes it instead.
- Breaking: `attach()` on a hosted provider no longer reports `snapshot`, `cpus` or `memoryMb`, and a retried create is no longer refused for a size the vendor reports differently. `list()` on a hosted provider reads each machine from the listing alone, with no read per machine.
