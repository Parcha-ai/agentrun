Console: a run's live screen on the Screen tab has the run's steps so far beside it, in the Timeline tab's words, so what the agent is doing is read next to where it does it. The list stays at its newest step as steps come, until you scroll up to read an earlier one; under it a line says the run is working. With its steps beside it the Screen tab's panel is wider than the reading column, so the live view (and a finished run's recording) keeps the size it had alone; on a narrow window the steps sit under the screen.
