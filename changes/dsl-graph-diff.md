`@parcha/agentrun-dsl/graph` exports `graphDiff(prev, next)`: what changed between two graphs of a workflow, such as two saved revisions of one, as `{ added, removed, changed, moved, edges: { added, removed } }`. A node is the same in both when its `(kind, label)` is unique in each graph, so a step inserted before others reads as one added node and the steps after it moved, never as a run of changes; a node whose `(kind, label)` repeats, or is in one graph only, is matched by its path, and the same path with a new kind or label is changed. A matched node whose kind and label stayed but whose own fields changed (new instructions, a new budget) is rewritten, so a revision that only rewrites steps no longer reads as no change. For that, every node `workflowGraph` returns carries a `changeCheck`: 8 hex digits, the FNV-1a hash of the node's own fields as canonical JSON, its children left out. It detects a change; it is not an identity. Added nodes and edges carry their paths in `next`, removed ones their paths in `prev`. The module still imports nothing.
