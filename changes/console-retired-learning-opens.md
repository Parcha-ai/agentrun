On an agent's Learning tab, a retired note, skill or workflow opens to its text, read-only, as one in use does: when it applies, what it says, the run that learned it, and who retired it when. It was only a crossed-out name. No Edit, Approve or Retire on it: no later run reads it. Restore makes it active again, after a confirm, on the version its row shows; a version changed since, a token's call, and a refusal by the checks a new one passes each say so in plain words, and it stays retired. A card says its newest change as the server names it (approved, restored, retired, edited or created by you, with when), and a retired one who retired it and when; an older server keeps the learning log's line.
The "Waiting for your OK" box says a run's bash on the host runs as you only for an agent that runs on the host: one whose definition places it in the sandbox runs no bash on the host, and is not told so.
