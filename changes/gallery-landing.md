The run viewer's gallery opens on a hero and the featured runs as cards, each card written from its own run: its title, its question and a picture it holds. Only a run a real model made is featured. A card can show the boxes its run's own report marked for the looks the gallery's lock names, each with the report's label, on the picture the run's judge was shown. The list below shows each run's title, and opening a recording folder sits behind a link.
The README links the gallery.
