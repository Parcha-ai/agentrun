A run with a browser has a Browser tab on its page: the agent's page, live, while a browser session is open (the tab reads "Watch live"), and "Waiting for the browser" while the run can still open one (queued, working, or waiting on its question). On a run that ended, it says the browser closed with it, adding that a follow-up opens a new one only where the run takes a follow-up. It reads `GET /v2/runs/{id}/browser` while the run is live, and once after it ends; the served state decides, and a run with no browser (`off`) has no tab. The session's viewer is the address of an iframe sandboxed to its own scripts, origin and form (its address bar), and nothing else. Only a viewer on the console's own origin, under this run's own live-view path, is framed; anything else reads "The live view can't be shown here." with no iframe. Taking over and handing back are the viewer's own. The viewer's token stays in the address's fragment, and never reaches the console's address bar, its history, storage or a log. A new session after a release gets a new viewer, which the tab follows.
