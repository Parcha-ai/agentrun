The console sets which provider serves each tool that has a choice, such as web search and web fetch. Settings → Tools is the server's own choice: each tool's providers in the server's order, the default first, what each resolves to on each harness, and a change saved at once. A pick unlike the default is marked, and can be reset. The agent editor's Tools step sets an agent's own provider over the server's, saved with the agent's definition. It says what the provider resolves to for that agent once the change is saved.
