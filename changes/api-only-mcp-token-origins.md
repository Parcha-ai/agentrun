An API-only server's token (`AGENTRUN_API_ONLY=1`) also saves a `per_run` MCP server (`PUT /settings/mcp-servers/{name}`), which keeps no credential (each run hands its own), at an origin the operator lists in the new `AGENTRUN_MCP_TOKEN_ORIGINS`: comma-separated exact origins, each `https://host[:port]`, or one loopback origin (http on `127.0.0.1` or `[::1]`, with its port) that counts only with `AGENTRUN_MCP_ALLOW_LOOPBACK=1`. An entry with a path, query, fragment, user or wildcard stops the server's or runner's start, in words; unset, no origin is listed. An address at any other origin (a lookalike host, another port, a path that names a listed one) is `422 not_an_option` under `url`, naming no listed origin; any `auth.type` but `per_run`, or none, is `403`. The save's `toolkit` is recorded, so a template's need for that toolkit maps onto the server at an apply, and the token may delete the server. Each run's start checks the server's origin against the server's list again, and each run's claim against the runner's own: one no longer listed is refused by the server's name (`409 agent_not_runnable` at the start, before any run is made), and nothing is sent. `GET /capabilities` lists the variable under `switches`, with the origins as the server counts them.

An owner's OAuth sign-in on a server the token saved makes it the owner's, as an owner's save does, so the token's save over it and its delete are `403`. A token's Composio save that names an auth config another saved server made uses that config and leaves it the other server's: that server's delete still removes it at Composio, or hands it to a server that still uses it. A refresh of a server's tools (`POST /settings/mcp-servers/{name}/refresh`) never writes back over a save that moved the server or changed its auth type while the refresh listed: it writes nothing and is `503`, to be read again and tried again. A save that kept the address and auth type (new prices, say) stands too, even one in the same millisecond as the refresh's read: the refresh keeps its listing on top of that save, with the save's prices, never the ones it read.
