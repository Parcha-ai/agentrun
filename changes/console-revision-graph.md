The console's agent History has **View** on each of a workflow agent's past revisions. It opens that revision's workflow as its graph, read-only and marked against the current revision (new, edited, removed, moved), with **Make current** beside it and **Back to History**. A read-only view takes no edit, asks the server for no check, and has no save. An agentic agent's History is unchanged.
