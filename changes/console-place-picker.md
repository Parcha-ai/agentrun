The console sets and shows where an agent runs. The editor's Settings step picks On the server or In a sandbox, with a box from the server's list; a box the server lacks is greyed with its reason. Picking a box opens bash, and going back to the server turns bash off and says so. The agent page says where the agent runs, and the run page where the run ran. A start refused for a missing box says which box. A tool the server can't run shows the server's reason, and a refusal at one tool shows on the Tools field.
