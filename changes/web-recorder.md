The web example records a run: with `RECORD_DIR` set, the agent app writes an agentrun.recording/1 directory with the reference recorder from inside the run (every document's lines, none dropped, pi's live events and the frames the frame store keeps), and start-run.mjs finishes it once the run has exited, with the agent's `report/index.html` as `manifest.artifact`. The Browserbase key, the browser profile's id, live views and any `token=` value are `[redacted]`, a session's id is a label of its hash, a document's `liveView` is null, and the machine is scrubbed; the run and the finish both scan for every id. A replay (`writeReplay`) takes the same browser ids, tokens and live views out of its rows, text files and records, by the one set of rules both use (`agent/redact.ts`). The site-report skill also writes `report/index.html`, one script-free page. The reference entry exports `redactorOf`, `runScrub`, `scanRecording`, `scanPlaced` and the `Secret` type, so an example that records a run of its own uses the reference's redaction and scans.
