Connect GitHub end to end: a server makes its one GitHub App with GitHub's app-manifest flow, a `github` trigger source runs on it, and its runs get GitHub tokens from it. `POST /v2/integrations/github/connect` answers the manifest form the console posts to GitHub (`action` with the state in its URL, the public hook `/v2/hooks/github`, its callback and setup URLs, pull requests write and contents, metadata and issues read, the `pull_request` and `issue_comment` events); the callback converts GitHub's code and keeps the App's private key and webhook secret sealed (never its client secret), and the installed redirect records an installation GitHub confirms to the App's JWT. Both browser legs send the browser to the console's `/#/settings/github`, `github=connected` or `github=error&reason=state_invalid|conversion_failed|installation_unverified`. `GET /v2/integrations/github` shows `{app_id, slug, installations}`; `DELETE` disconnects it, turning every github trigger off and keeping them, and names the App's settings page on GitHub to delete it there. Refusals are `409 github_no_public_url` (it needs `AGENTRUN_PUBLIC_URL`), `github_no_seal_key`, `github_already_connected` and, for a github trigger with no App, `github_not_connected`. A trigger `{kind: "github", accept: [...]}` keeps no secret: one signed event fires every github trigger whose accept takes it, each its own firing (keyed by the body's SHA-256) and run, with the installation and repository on the payload's tag; an ignored body keeps its key for the day, since GitHub does not sign `X-GitHub-Event`. An installation deleted or suspended leaves the list, and the github triggers turn off (`disabled.reason: "connection_lost"`) only when none is left. An MCP server saved with `auth: {type: "github_app"}` gets, at each launch of a run (start and every resume), an installation token narrowed to the run's one repository (its event's, or the one its input names), beside the server's static headers, in memory only and cut from whatever a run shows. A server-wide pushed source may now fan one event out to every trigger that takes it, a trigger's own hook is checked by its own source, and two sources on one hook route refuse to start. Upgrading: nothing to do.
