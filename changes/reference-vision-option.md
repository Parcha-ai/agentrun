The reference entry files every look the vision guard reports into a `vision.looks` document of the run's store, with the screenshot it was of as a blob and its evidence path as its receipt, so the recording's counters read the eyes' looks and cost; a demo passes only its eyes (`fakes.eyes`). `vision.filing` is the first of the packages' own kill crossings: the eyes have answered and the look is not yet filed, so the next process files the kept answer and does not ask the eyes again. A planned kill that never lands is reported (`unlanded`) and the command exits 1.
