**The transport panel places a process on a host box a later supervisor life adopted**
- An adopted host box gets no second `box.created` (draft 56, Amendment 2), so in a recording of host boxes only, the later process's runner stayed at "?" after a restart. Its first `box.exec` on a host box already created, and not ended, now places it: the runner, the kills it recovered, its stretch of the session's trail, and the session and the browser tile when nothing else placed them. A `box.ended` never places a process. The process's own `box.created` replaces this guess.
- A session whose box ended waits for a recovery. When the current process then makes its own box (an adopted box ended and replaced), the session now comes back in that box; it stayed on the ended box before.
