`@parcha/agentrun-dsl/recovery` builds a handoff from an escalation the driver committed: `buildHandoff(journal, options)` returns the bounded, redacted block and digest a continuation reads first, the attempt written as files under `evidence/frozen/`, and the receipts and unknown effects the journal hands over (`inheritableReceipts`, `inheritableUnknowns`, `gatewayIntentOf`). An input field named like a credential is never copied, and a failed file write is reported on the handoff, not hidden.
