Connect existing Claude Code projects or named agents and Codex projects or profiles on the source machine. Native jobs preserve the original project, configuration, sign-in and permissions while AgentRun records their runs and supplies checked, graded, versioned notes and skills when Self-improving is On. Off supplies and creates no AgentRun learning. Native usage remains unknown where the CLI cannot report it; interactive approvals, dollar-cap enforcement, learned workflows and hosted pairing are explicitly unavailable.
