`@parcha/agentrun-client` is published from this release on: `npm install @parcha/agentrun-client` installs the typed TypeScript client for a self-hosted AgentRun server, at the release's version, with no dependencies. The release checks it as it checks every published package (its manifest, its packed files, and a clean install that imports it and calls a fake server with no network).
