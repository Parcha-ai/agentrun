`osw` (`packages/computer-bench/image/osw/osw`), the runtime that runs an OSWorld task's own setup and evaluator inside a bench desktop image, so a task ports as OSWorld's JSON instead of a hand-written check. `osw setup <osworld.json>` starts OSWorld's in-VM server on 127.0.0.1 as the desktop user, runs the task's `config` through OSWorld's `SetupController` and stops the server (the apps it launched stay up). `osw eval <osworld.json>` starts it again, runs `postconfig`, then each getter and metric with its options and `conj`, as OSWorld's `DesktopEnv.evaluate()` does. Every download and gold is fetched by URL and checked against the sha256 the task pins; golds are fetched only by `osw eval`, after the agent has ended, into a folder only its owner reads. It exits 0 for a score of 1, 1 for a lower score, 2 for a task it can't check, and 75 when the check could not run (a getter or metric raised, a download's sha256 differs, the server didn't start). OSWorld's code (Apache-2.0) is not in this repository: `osw` imports it at run time from the path `--osworld` or `OSW_OSWORLD` names.
