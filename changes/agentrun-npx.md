`npx @parcha/agentrun` starts AgentRun on this machine with one command. `@parcha/agentrun` 0.3.0 is that command alone, with no dependencies: it checks Node, takes the first free port from 7340 on the loopback address, keeps its data in `~/.agentrun`, starts the server, waits until it answers, prints on one line the address the server says to open (the URL of its `Open` line) and opens it (not with `--no-open`, in CI, or with no display). The server, `@parcha/agentrun-serve`, runs from an install beside the command, else `npm exec` fetches its latest release. With `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` or `OPENROUTER_API_KEY` set and no `AGENT_MODEL`, the server runs a current model of that provider. Other commands go to the server's CLI: `npx @parcha/agentrun import`. The TypeScript SDK for the hosted API stays `@parcha/agentrun` 0.2.x; a dependency on `^0.2` never gets 0.3.0. The release publishes `@parcha/agentrun` at its own version, first, and `changes --check` fails a change to the files it ships that keeps its version. The README's first run is two lines, Docker and Render move under "Run it on a server", and `docs/SKILL.md` is the setup skill for a coding agent.
