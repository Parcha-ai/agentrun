Goose 1.59.2 no longer asks permission for a call of one of AgentRun's tools, and the ACP adapter no longer reads Goose's titles. Before, it tied `agentrun: <tool>` (with or without Goose's summary, `agentrun: write · proof.txt`) to our tool and answered `allow_once`, and a title in a form it did not read reached the tool gate as Goose's own call and stopped the run at input_required.
- A recipe's new `allowFile` (`{ path, form }`) is written into the private HOME at each start from the tools that start lists. Goose's recipe declares its permission file, `.config/goose/permission.yaml` in the form `goose-permission`, every tool allowed as `agentrun__<tool>` and nothing else, so the gate asks once, at the MCP call.
- The adapter answers a permission request `allow_once` without the gate only where the recipe declares `quirks.permissionTie: "title"`: Cursor's recipe alone, since its allowlist asks for every MCP call. Every other request goes to the host's gate, journaled, whatever its title says.
- A recipe's new `announces` field says where the agent's `tool_call` names the tool it calls: Goose 1.59.2's `_meta.goose.toolCall.toolName` (`agentrun__<tool>`), Cursor's late update's `rawInput` (`providerIdentifier`, `toolName`, `args`). A path that starts at the `tool_call`'s `title`, `toolCallId`, `kind` or `status` is refused, and a recipe with the title tie and no `announces` is refused. A call is matched to its MCP call by that tool and its arguments, never by a title. A call it names as another tool (Goose's own `load_skill` with the same arguments) never takes our call's id, so the resume memo keys our call under its own id.
- A title naming our tool on a call of the agent's own (a read titled `agentrun__write`) no longer marks it ours, so Cursor's tie never answers its request; the host's gate does.
- The host gate's question about an agent's permission request carries the request's `toolCallId` in its `args`. `agentrun harness-check` matches a permission request to `check_echo` by that `toolCallId` or by the check's nonce as its input's `text`, never by its title. Its `mcp_tool` row counts every request (`permissionAsks`) and those for `check_echo` (`ourAsks`); a request for the agent's own call fails no stage. A recipe file passes `allowFile`, `announces` and `quirks` through.
