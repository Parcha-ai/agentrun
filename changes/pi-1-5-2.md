The pi family and Chord move from 1.5.0 to 1.5.2 together (pi-ai, pi-agent-core, pi-coding-agent, pi-codemode, pi-durable, chord). Pi's model catalog now lists `claude-fable-5-2`, so a pi run can use it. Chord's package root no longer exports `Context` or `JsonValue`; they come from `@earendil-works/chord/context` and `@earendil-works/chord/json`, which a host that imports them from the root must follow.
