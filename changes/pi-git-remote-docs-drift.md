The README and doc comments say what the code does. The method table lists `fetch()`, documents revert's `trailers` option and its `Reverts` trailer, and says that `log()` gives an empty list for a ref with no commit. "package A's caps" now points at the Limits section. The platforms are named: Linux and macOS, because the credential helper reads `/dev/fd/3`, a timed-out git is killed with its process group, and seed records are opened with `O_NOFOLLOW`. `EndOutcome.sha` is the branch tip after the end, undefined only when the branch did not exist and there was nothing to commit. The extension's `allow` is required whenever a remote is configured: a missing or empty list is refused, not read as "commit nothing".
