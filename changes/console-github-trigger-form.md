The console makes GitHub triggers. New GitHub trigger on the Triggers page picks the events it takes (a pull request opened, given new commits or reopened; a comment on an issue or pull request), then the agent each starts a capped run of, and sends its create with an Idempotency-Key. It's offered while GitHub is connected (the connection read names the App); with none, the page says "Connect GitHub first: Settings → GitHub", with the link and no form, and a 409 github_not_connected shows in the server's words. A GitHub trigger's row in the list reads GitHub on its chip, not Schedule.
