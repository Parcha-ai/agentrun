serve's Workspace port gains attach, the background surface, output streaming and place resolution, still unused until the cutover. A Workspace says what a computer mounts at /workspace to hold its folder (`mountSpec`: a bind of the run's folder for a local computer, or the run's folder on the owner's disk). `attach(computer)` checks the computer's read-back of that mount and hands back an attached Workspace whose file calls and exec go to the computer's computerd client (the computer protocol's types, imported), and whose `process` is the computer's background processes. With no computer, every background call is refused with a typed error (REFUSED, cause "no-computer"); the words a person reads belong to the background tool. exec takes `onOutput`, which gets the output as it comes (or once per stream, from a backend that cannot stream). `resolvePlace` turns an agent's place into a computer or none, from the provider ids and mount kinds the computer registry passes in: an absent place is the first local computer that answers in Mode 1, else the runner; a workflow always gets the runner; Mode 1 refuses every remote computer, Mode 2 every local one; a provider with no key is refused.
