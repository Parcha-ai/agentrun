Cursor runs as a harness (`cursor`), over ACP, on its owner's own Cursor API key: install its pinned release with `agentrun harness install cursor` (or `agentrun-serve install-harness cursor`), set `CURSOR_API_KEY` where AgentRun starts, and restart. Each run is billed to your Cursor plan, under Cursor's terms, with no spend cap of AgentRun's: it stops after 20 turns or 100 tool calls (`AGENTRUN_CURSOR_MAX_TURNS`, `AGENTRUN_CURSOR_MAX_TOOL_CALLS`), and capabilities show its card (`harnesses[].card`).
- Cursor makes no file edits: every Write is denied in its CLI config until Cursor asks before an edit, as it asks before a shell command or a tool. Cursor's own shell commands run on AgentRun's host, not the run's computer: each is asked of a person who can approve it, and refused where no one can.
- `CURSOR_API_KEY` is handed to Cursor's runs alone, read by name at each start. The credential Cursor derives from it (`auth.json`, which would hold its tokens and the key itself) is never written: its path is a folder Cursor cannot write a file at, and Cursor runs on the key in its environment, so a killed run or server leaves no credential on disk. Cursor's warning that it could not save one is left out of a failed run's words (a recipe's `quiet`). Its whole private HOME is deleted when its process ends.
- A model is `cursor/<model-id>` (`cursor/gpt-5.4-nano`; `cursor/default` for Cursor's own default), checked against the models Cursor lists for the key (`ACP_MODEL_UNLISTED`). A key whose Cursor team administrator turned headless CLI use off is refused as `CURSOR_HEADLESS_DISABLED`.
- The release is pinned by its archive's sha256, its launcher's, and a digest of every file it unpacks to; a drift in any of them refuses the run (`ACP_BINARY_MISMATCH`). The archive installer takes tar.gz as well as tar.bz2 (`ARCHIVE_FORMATS`), and so does a harness recipe's loader.
- Cursor's release is pinned for linux-x86_64 alone. On any other host, a Mac included, Cursor is refused `ACP_BINARY_UNPINNED` before any install is looked at.
