The store page shows an agent's revisions as versions, Version 1 for the oldest, each with its note and its hex id as a small detail, the current one marked in use; a stored run is titled by its input's first line (else its agent and start), its id a small detail, and its version numbered from its agent's. The host's parts include `versionOf`, `versionName` and `revId`.
