Connect selected Claude Code and Codex setups on another machine through the existing AgentRun CLI's opt-in remote worker. Scoped enrollment, source-local selection, leased commands and revocation preserve native credentials and permissions while the ordinary run and checked learning pipeline records jobs and supplies accepted notes and skills to later sessions. Interrupted remote dispatches are not replayed. The console uses one Connect agent handoff for live connections or optional history import and serves the skill matching its build; historical transcript upload and attachment to existing desktop conversations remain unavailable.
