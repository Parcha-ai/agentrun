Connect selected Claude Code and Codex setups on another machine through the existing AgentRun CLI's opt-in remote worker. Scoped enrollment, source-local selection, leased commands and revocation preserve native credentials and permissions while the ordinary run and checked learning pipeline records jobs and supplies accepted notes and skills to later sessions. Interrupted remote dispatches are not replayed. One Connect agent handoff offers live connections, selected project history, or both using the skill matching the server build. History requires separate owner and source approval; history-only imports start no worker or learning, preserve source provenance and skip duplicates. Attachment to an existing desktop conversation remains unavailable.
