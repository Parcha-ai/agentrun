kind: breaking
---
E2B computers run on one shared machine-host adapter (`hostedProvider`, `MachineHost`); a vendor now writes only create, get, list, delete, exec and, when it has a file API, upload. Breaking: `E2BProvider`'s `listLabelled`, `killById` and `probeGone`, `diagnoseNetworkNone` and `dist/conformance/e2b-diagnose.js`, `dist/conformance/e2b-sweep.js` and `dist/child.js` (`childCommands` and the daemon read-back, now `dist/hosted/scripts.js`) are gone; sweep a live run with `dist/conformance/sweep.js --provider e2b`.
Breaking: `ComputerProvider.create(spec, context)` takes a required `context.requestId`, the caller's id of the request (serve passes the run's claim, `<run>#<epoch>`). A provider on the adapter names the computer from it, so a retry of the same request returns the computer the first one made instead of making a second, and a retry of one that ended is refused as `exists`; a create without one is refused as `invalid`. Pass a request id on every create.
Two creates of one request on two provider instances converge on the oldest machine (`Machine.createdAt`, else the lowest id) and delete the other. `HostedOptions.archilEgress` gives an Archil computer's mount an egress gateway, and `HostedTimeouts.listedStableMs` (default 1 s) is the listing wait's stability window.
A host whose `specFields` holds `user` runs each computer's daemon as the spec's uid (or uid:gid), never root unless the host allows it, and `attach` reads it back; a host with `facts.runtime` has the probe's kernel held to it at create. A pid1 install moves the daemon into place only once it reads the sha256 uploaded, then writes the create's nonce to a marker beside it, and the entrypoint starts only a daemon whose marker holds that nonce (never one already in the image); and a pid1 Archil computer's gate is `/opt/agentrun/archil-mounted`. `dist/conformance/sweep.js` records where a provider lists when its conformance module exports `sweepScope`, and refuses a before file of another place.
A second create of a request still in flight with another spec (labels, user, or any field the host takes) is refused as `exists`, as a retry after it is made is. A process the adapter kills after a timeout or an abort is waited for at most its own bound, so a kill the vendor never answers no longer holds up the machine's delete.
