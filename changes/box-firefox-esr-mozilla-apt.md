The box image's `install.sh` builds on Ubuntu 24.04, as a vendor whose base is Ubuntu builds it. Ubuntu has no `firefox-esr` (its `firefox` is a snap), so where `apt-cache policy firefox-esr` reads no candidate, the desktop step installs it from Mozilla's APT repository: the signing key is fetched over https and the build stops, naming both fingerprints, unless the file holds that one key, `35BAA0B33E9EB396F59CA838C0BA5CE6DC6315A3`; `/etc/apt/preferences.d/mozilla` lets `packages.mozilla.org` supply `firefox-esr` and its `firefox-esr-*` packages and pins everything else from it at -1. A Debian base, the Dockerfile's, keeps its own `firefox-esr` and never reaches Mozilla. The box recipe's hash moves to `91bc4d1eed97`, so the next release publishes `ghcr.io/parcha-ai/agentrun-box:91bc4d1eed97` and its E2B template, a Daytona box snapshot is built again as `agentrun-box-91bc4d1eed97`, an account-built box image (Morph's snapshot, Render's build, Agent37's template) is built again at its next `prepareImage`, and the relay's pinned image changes with it (`relays/cloudflare/wrangler.json`, redeploy the relay).
