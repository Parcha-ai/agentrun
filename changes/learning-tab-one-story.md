The Learning tab tells one story: one run numbering, one takeover, one cheaper ratio and one figure for what learning costs a run, each read from the server once.
  - `GET /agents/{id}/learning/cost` numbers the runs that do a job as the bill does: a run's `n` is its job's number and a replay run's is null (it does no job). `summary.takeover` is the bill's `promoted` run, the first run a learned workflow served, alone or handed back. Each run has `digest`, the workflow revision that ran it (null for the agent's own), and `audited`, whether an audit's shadow run checked it, in place of `learned_revision` (the learning folder's commit, which moved with every audit). The CSV has `digest` and `audited` columns. `bill.learning_usd` is what learning booked beyond the jobs' own cost, and `bill.revisions[].served` counts every run a revision served, not only the ones that carry its spend.
  - `GET /agents/{id}/learning`'s `impact` sides no longer have `median_learning_usd`: what learning itself costs a run is the bill's `learning_usd` over its runs, which counts the audits' shadow runs and replays a median of mostly-zero rows read as $0.
  - The console's Learning tab: the cost chart, its table and markers number jobs only (a replay is drawn between the jobs it came between, unnumbered); the cheaper stage says the chart's ratio ("7.7x cheaper", never "About 8x"); answer times show to a tenth under 10 seconds, with the change of the times shown; "Learning itself" is the bill's figure a run, booked; the levels and the bill's end labels sit in a gutter right of the plot, off the lines; the bill's dollar axis tops out just above its largest figure; an audited row says so in the table; the audit card counts the audited runs the ledger has not scored yet; and the captions say compile turn and audit shadow run, not look-back, grade or notes.
  - Upgrading: read a cost run's `digest` and `audited` instead of `learned_revision`, allow a null `n` on a replay run, and read what learning costs a run from `bill.learning_usd` instead of `impact.after.median_learning_usd`.
