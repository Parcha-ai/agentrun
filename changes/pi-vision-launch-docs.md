The README names the `report` skill beside `look`, `transcribe`, `find` and `verify`, and its status table has rows for the skill and its check. It points to `examples/vision-agent`, the one agent any question about a set of files goes to, and to the examples beside it, as the place to start; the root README's pi-vision rows do the same. The vision agent's README says that Jev reads images and answers box questions as TypeSafe early features whose format and limits can change, that the runner sends the header that turns them on, and that a TypeSafe key is needed because the runner refuses images and boxes through OpenRouter.
