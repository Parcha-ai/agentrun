The README names the `report` skill beside `look`, `transcribe`, `find` and `verify`. It points to `examples/vision-agent`, the one agent that answers questions about a set of files, and to the examples beside it, as the place to start; the root README's pi-vision rows do the same. The vision agent's README says that Jev reads images and answers box questions as TypeSafe early features whose format and limits can change, that the runner sends the header that turns them on, and that a TypeSafe key is needed because the runner refuses images and boxes through OpenRouter. The README opens with what the package is, a free `npm run demo:vision -- examples/document-check`, the keys and programs a live run needs, and the pi-durable host it runs inside, before any term the reader has to learn. Every example README lists its free path, its keys (the lead model's, `TYPESAFE_API_KEY` for every live run, `FAL_KEY` only for speech), its programs and its download, and the cost and time one measured live run took where there is a measurement.
