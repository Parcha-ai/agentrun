A smol cloud provider: `providerFor("smolcloud", { apiKey })` makes each computer a smol cloud machine, a microVM booted from an OCI image (default `alpine:3.20`), as a sandbox. It is a `MachineHost` on the shared adapter: `src/smolcloud.ts` calls smol cloud's REST API with `fetch`, and the daemon runs as a child of a resumable interactive exec, its output read by offset and its stdin sent as numbered frames. The daemon is uploaded through the files API. Network none, open and a list are init's. Its lifetime is the janitor's, by the deadline label; the idle stop is off and smol cloud's delete timer ends every machine at the adapter's backstop. Machines are named `agr-<computer name>` and placed on amd64 nodes. No mount and no desktop yet. Settings takes `SMOLCLOUD_API_KEY`. `AGENTRUN_COMPUTER_LIVE_SMOLCLOUD=1 COMPUTER_SMOLCLOUD_API_KEY=... npm run conformance -w @parcha/agentrun-computer -- --provider smolcloud` runs the conformance kit on real smol cloud, and `sweep.js --provider smolcloud` checks it left nothing behind. The shared REST client takes a raw body (`bytes`) for an upload.
