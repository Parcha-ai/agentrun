Remote MCP servers can be previewed and saved through `/v2/settings/mcp-servers`. `POST .../preview` connects over Streamable HTTP with the official MCP SDK client (2026-07-28 first, 2025-era servers by their `initialize`), lists every tool and stores nothing; it answers `422 auth_required` with `details.auth` `bearer` or `oauth`, `422 not_mcp`, or `424 upstream_failed`, and never follows a redirect. A server is kept with at most 500 tools and 1 MiB of them; past either it is `422` and nothing is kept. `PUT .../{name}` previews, then keeps the URL, the tool snapshot and the credential (`none`, `bearer` or named `headers`), each value sealed under `AGENTRUN_SEAL_KEY`; with no seal key a server that takes a credential is `409 no_sealing_key`. Reads say `credential: sealed | seal_key_missing | unreadable` and never show a value; a `PUT` without the credential keeps the sealed one while the auth type and the URL's origin are unchanged. `POST .../{name}/refresh` answers what was added, removed and changed; `DELETE` forgets the server. A saved-servers file that does not read is never written over: reads say `file_unreadable`, and writes are `409 store_unreadable`. Capabilities gain `features.mcp_client`. Agents do not use these servers' tools yet.
