A revision may name `fetch_page`: one web page from a public host, `{url}` in and a Page out, `{ok, url, status, title, text, links, refused?, error?}` (the text cut at 60,000 characters, at most 200 absolute http(s) links). An agent gets the Page as JSON text, and a workflow's `call` node `via: "tool", tool: "fetch_page"` runs it and gets the Page as its output: workflows now get a tool adapter beside their model nodes, for the table's tools that a call may run, and a call to any other tool is `409`. It needs no key. It reaches public hosts only, on pi-browser's guard: each redirect hop resolved, checked and dialled at the address checked, http(s) only, at most 5 MiB and 30 s. A loopback, private, link-local, carrier-grade or metadata address, a local name, a public name that resolves to one, a redirect to one, and `file:`, `data:` or `ftp:` are refused as a Page with `ok: false` and `refused`, never a thrown error, so a workflow can branch on it. Capabilities show `calls` for each tool.
