New example `examples/placed-frames/` (`npm run demo:placed`): a zoom into the Mandelbrot set, twelve frames, each one tool call that Jev places on a Daytona or a Modal sandbox, where it is drawn. Each frame's answer names its sandbox by label and one line on why, composed from the placement record's fields. With no key both sandboxes are local boxes and a script stands in for Jev, and every answer says so; `--live` uses your own Daytona, Modal and TypeSafe accounts. The job asks no model.
