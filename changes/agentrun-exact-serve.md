`npx @parcha/agentrun` installs the server it was released with: `@parcha/agentrun-serve` is its one dependency, at the release's exact version, so npx installs the two together and nothing is fetched at run time (no `@latest`). The command passes its arguments through, with its store (`--data ~/.agentrun` unless `--data` names another), and the server's CLI picks what it used to: with no `--port`, `agentrun-serve` takes the first free port from 7340 (`--port N` is still exact, `0` any); `--open` opens the console in the browser once the server listens (with accounts off, the sign-in link the banner prints when the start made the token), except in CI or on Linux with no display (the command passes it unless `--no-open`); and with `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` or `OPENROUTER_API_KEY` set and no `AGENT_MODEL` or gateway, the server runs a current model of that provider, which capabilities shows as its default. The release publishes the command after the server, and `release-preflight` refuses a command whose server pin is not the release version, so every release bumps the command too. `@parcha/agentrun` is 0.3.2.
