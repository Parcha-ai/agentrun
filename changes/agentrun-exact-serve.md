`npx @parcha/agentrun` installs the server it was released with: `@parcha/agentrun-serve` is its one dependency, at the release's exact version, so npx installs the two together and nothing is fetched at run time (no `@latest`). The command passes its arguments through, with its store (`--data ~/.agentrun` unless `--data` names another), and the server's CLI picks what it used to: with no `--port`, `agentrun-serve` takes the first free port from 7340, found by listening, so a port another process takes at the same moment is passed over (`--port N` is still exact and fails at once when taken, `0` any); `--open` opens the console's page in the browser once the server listens (never the banner's sign-in link, so the token stays out of the opener's arguments and the browser's history), except in CI or on Linux with no display (the command passes it unless `--no-open`). The CLI sets no model: with no `AGENT_MODEL`, the server's default is the first provider key it has, set where it starts or saved in the console's Settings → Model keys, so a key saved later moves the default with no restart. The release publishes the command after the server, and `release-preflight` refuses a command whose server pin is not the release version, so every release bumps the command too. `@parcha/agentrun` is 0.3.3.
