The `report` skill grounds the page before it writes it. Each finding, each row and the answer is put to Jev as a text judgment (`vision.judge` with no image): the texts it shows as `claims` and what the looks it cites read as `evidence`, one noul question for each text asking whether the evidence states every name, time and number in it. Every text the page shows is judged (the title, the question, a row's label and text, a picture's alt text and caption, the answer and its key points), against what the looks it cites read and where each cite points. A text that is not grounded stops the script, naming it, and is rewritten from what the looks read, re-cited, or dropped; it is never kept as written. What was heard is cited to the transcribe look (`hear()`), the only evidence for a said name, time or number. `hear()` also records the recording it heard as covered, so it cannot be listed as not checked. The page is a pure function of that data, and the check renders it again and compares it with `report/index.html`, so a text added to the page by hand is refused. The skill's check refuses any text that was not judged as written. `test/binaries/report-skill.test.mjs` runs the step on a fake Jev port and shows a row with an unread name refused and the same row passing once a look it cites gives the name.
