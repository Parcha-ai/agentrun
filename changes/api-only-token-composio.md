API-only (`AGENTRUN_API_ONLY=1`): the token's Composio save now stands on nothing the owner's does, and its Composio users have a namespace of their own. A backend whose token saved a Composio server in 0.1.0-beta.56 or earlier connects its account again after the next save of that server. The token's save (`PUT /settings/mcp-servers/{name}/composio`) that is not `per_run` reaches Composio, and its server calls, as `agentrun.token.<user_id>` (no `user_id`: `agentrun.token.agentrun`), a user that, through this install, only the token's own connect link connects; its `user_id` is at most 113 characters. No save names a `user_id` starting `agentrun.token.`, the owner's included: `422` under `user_id`, before anything is sent. A server the token saved before keeps calling as its bare `user_id` until it is saved again: that save moves it to the namespaced user, returns a connect link for it, and deletes at Composio every account its record holds as made here under the bare user unless another saved server stands on it. Or delete the server. The token's save never uses an auth config a server the owner saved uses: naming one (`auth_config_id`) is `403`, and so is a save whose toolkit's own auth config, as Composio answers it, is that one, before anything is made at Composio. An `auth_config_id` Composio answers under another id (another letter case, say) is `422` under it, for any save. Nor does the token's save stand on an ACTIVE connected account it did not connect: each one Composio already has for that user under its auth config is `403` before anything is made, unless a server the token saved holds it as one it made. The lookup reads 50 accounts a page, at most 10 pages: past that the token's save is `403`, and an owner's save goes on with the ones it read. A `per_run` save names no user, so none of this applies to it. `GET /capabilities` lists `AGENTRUN_API_ONLY_MCP_ORIGINS` under `switches`, saying only whether the list is set, and the start banner names the per_run save it serves. An `AGENTRUN_API_ONLY_MCP_ORIGINS` entry that is plain `http://` to a host other than a loopback one (127.0.0.1, ::1, localhost) now stops the start, naming the entry by its place: list that host's origin as https.
