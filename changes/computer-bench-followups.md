Two findings of the sandbox bench: large reads from a Daytona computer were slow, and the desktops lacked apps the linux-desktop suite opens.
- A `files.read` past one chunk (512 KiB), of a file of at most 16 MiB (the surface's read limit), on a Daytona computer over `connect: "exec"` now comes through its toolbox's `GET files/download`, not the stdio bridge, which on Daytona is a session command's log read at about 0.3 MB/s. The daemon still answers the first chunk, so a file its user can't read is refused as before. The rest comes from one copy that the adapter makes as the daemon's user (`setpriv --reuid --regid --clear-groups`, util-linux) in `/run/agentrun-read`, a directory only root can enter. The copy is made at the read of the second chunk, so a one-chunk preview copies nothing. It is downloaded whole, then removed, and one connection holds at most 32 MiB of copies, the oldest let go first. If a step fails, or the copy's size differs from the size the daemon read, the daemon answers the rest, chunk by chunk, as before. `MachineHost` takes an optional `download(id, path)`, read as root, and Daytona's host on `connect: "exec"` has one.
- The box image's desktop step adds Thunar, and checks for each app the suite opens (mousepad, xfce4-terminal, firefox-esr, thunar) and for its desktop file. The box image's recipe changed (hash `244e45e13f7f`, was `d289bcc6d0c2`), so this release publishes a new `ghcr.io/parcha-ai/agentrun-box`. A server's Daytona desktops need a new `agentrun-box-244e45e13f7f` snapshot (`box/build-daytona.py`) named in `AGENTRUN_DAYTONA_SNAPSHOT`. The Cloudflare relay's `BOX_IMAGE` names the new tag, so redeploy it once this release publishes the image.
- boxd's desktop recipe adds xfce4-terminal, and Firefox ESR from Mozilla's APT repository. Ubuntu 24.04's `firefox` package is a snap, and a boxd microVM runs no snapd. The repository's signing key is pinned by its sha256, and the recipe checks each app and its desktop file. The snapshot it names is now `agentrun-desktop-c565e8ca4274` (was `agentrun-desktop-bd9393567ea8`), and the first `prepareImage()` of each org builds it once.
