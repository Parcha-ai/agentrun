`@parcha/agentrun-import` reads GitHub Copilot CLI, a new source (`copilot`): each session's `$COPILOT_HOME/session-state/<id>/events.jsonl` (`~/.copilot` without `COPILOT_HOME`), and an older CLI's `session-state/<id>.jsonl`. `normalizeUsage("copilot", …)` takes the cache read and write out of `inputTokens` and keeps `reasoningTokens` as `reasoning`.
- Copilot writes no request's tokens to disk (`assistant.usage` is ephemeral). A session's tokens are the per-model totals of the `session.shutdown` each CLI process writes as it exits; a shutdown that holds the session's whole total (a CLI that keeps its accounting across processes) counts only what it adds. Each model's total goes on its last request in that process; the model's earlier requests there are `folded` into it (zeros, known), so the run is metered and the catalog prices it. A session with no shutdown, still running or killed, has tokens 0 and its requests unmetered. Copilot writes no dollar cost, so `cost` is `null` unless each request's tokens are known.
- Each model call is one request, keyed by its first `assistant.message`'s `messageId`; a response split into chunks (each its own `messageId`, one `apiCallId`) is one. Each event counts once by its `id` and each message by its `messageId`, so a copied session adds no request; a copied shutdown adds no tokens but moves the copy's baseline, so its next whole total adds only its own. A rotated journal's `checkpoint: true` records are copies. Subagent, autopilot, skill and agent-written user messages are not the person's turns.
- `agentrun-serve import` (and `--from copilot`) imports Copilot CLI sessions as runs. A turn's `folded: true` (its zeros counted in a later request of the session) is read as known tokens, never unmetered, so the run's estimate prices it. `imported_from.source` and the stats analytics' `by_source` take `copilot`, in the OpenAPI document and the generated clients.
