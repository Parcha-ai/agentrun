The kernel's spend cap, still unused until the cutover, prices a request the host sends beside the harness's own (a learned workflow's node) as a cache miss: the session's previous request never stands for it. A request carrying the wrap-up's note that fits only without the note is sent without it (`withoutNote`), and one that fits neither way is refused in the words for its client's own body. The note never refuses what fits.
