An agentic agent's page can cap one run: a Spend cap box beside Effort sends the run's `max_cost_usd`. Empty sends none, so the agent's default cap applies, and the box shows that default as its placeholder. A cap the server refuses is said at the box, in the server's words. A workflow agent's page has no box: a workflow run takes no cap.
