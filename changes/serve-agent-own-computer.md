An agent's own computer, kept between its runs. An agent's `computer` setting takes `persistent: true` where its provider keeps one for the kind and image (Orgo's Linux desktop; `GET /v2/computers` shows a provider's `persistent`), and is 422 `not_allowed` anywhere else. The agent's first run makes the computer under an owner of this server's id and the agent's. Each run's end detaches it (Orgo suspends it, memory and disk kept) instead of deleting it, and the next run attaches it again, saying on its timeline which happened, or that the computer was gone and a new one was made. A run that finds the computer held by another run still going, or being detached by one that ended, is refused at its start, naming that run. The hold is per claim: a resumed run's later claim takes it over, so the earlier claim's end detaches nothing, and an earlier claim is fenced. `GET /v2/agents/{agent_id}` shows it as `own_computer` (provider, id, name, and held, detached or deleting). Archiving the agent, turning `persistent` off, or moving the setting to another provider or image deletes the computer once no run holds it (a run's end deletes it then), and the janitor's sweep deletes an agent's computer only when its agent no longer wants it, never another server's.
