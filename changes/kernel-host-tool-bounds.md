The kernel's own host tools keep their results under the host's bound (`HOST_RESULT_MAX_CHARS`), so the Claude Agent CLI no longer saves one to a file the model cannot read, nor does Codex cut its middle. `read_skill_file` answered a whole file of up to 1 MiB; it now reads one as pi's read does, at most 2,000 lines or 50 KB from `offset` (a line number, from 1) and at most `limit` lines, saying which lines of how many it holds and the offset that reads on (`skillFilePart`, `SKILL_READ_MAX_LINES`, `SKILL_READ_MAX_BYTES`); a file read whole is its exact text, as before. `delegate` answered its child's answer whole; past `DELEGATE_ANSWER_MAX_CHARS` (60,000 characters) the lead reads it cut to fit, its JSON whole (the start of the answer's text, the citations and gaps that fit, and `cut` saying what was cut of each), with a line saying so and that the whole answer is kept in the child's records, which none of the lead's tools reads (`delegateText`). `submit`'s rejection listed every schema error; it lists the first `REJECTION_MAX_CHARS` (8,000) characters of them and how many there are. `KERNEL_HOST_TOOLS` names the host tools the kernel makes.
