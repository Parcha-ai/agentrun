The console's setup offers to import this machine's Claude Code, Codex and pi sessions. On a server on the same machine, the first-visit card shows a box with how many sessions and projects it found, and the box is never ticked for you. Ticked, setup asks the server to import them once the password is set. The console then shows the import running and then done, and it reads the agents' names again once the import ends. Where the server offers no import, there is no box.
