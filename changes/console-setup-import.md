The console's setup offers to import this machine's Claude Code, Codex and pi sessions. On a server on the same machine, the first-visit card shows the box at once, never ticked for you. It reads "Counting sessions…" until the server's numbers arrive, and the count isn't known if counting failed. Ticked, setup asks the server to import them once the password is set. The console then shows the import running and then done, and it reads the agents' names again once the import ends. Where the server offers no import, there is no box.
