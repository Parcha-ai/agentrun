New package `@parcha/agentrun-reference`: the reference host, moved from `examples/reference/` (history kept), so an example runs from an npm install. It exports `run`, `demo` (the supervisor that kills a run's process anywhere and resumes it), `localHost`, `placeAt`, the recorder and supervisor, `codeOf` and `cost`, with `./scan` (the one credential and machine-path scanner), `./child-app` (the app module `pi-durable-disk run --app` takes as a file: `import.meta.resolve('@parcha/agentrun-reference/child-app')`) and `./place`. The pi family (`pi-ai`, `pi-durable`, `chord`, `pi-codemode`) and `typebox` are peers; `@parcha/pi-transport` is an optional peer that only a demo declaring `boxes` needs, and such a demo says so in one line when it is missing. Its types need nothing from pi-transport (`Boxes` is its own type). A demo's repository root comes from the demo (`options.root`, else the nearest folder above the demo's file with a `package.json` or `.git`), never from the package's own location, and a recording made in another project names that project's GitHub `origin` as `owner/name` (else `unknown`) and the @parcha packages it loaded. `examples/reference/` keeps the example job, and every example imports the package by name.
