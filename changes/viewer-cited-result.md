A run's result can be the generic cited result, `agentrun.cited/1` (`apps/viewer/RECORDING.md` section 5): rows of a label, a value and an optional note, each citing a file in `blobs/`, a vision look by its key, or both, with where in it (`page=`, `t=`, `xywh=percent:`). The vision panel reads it beside `apollo11.account/1`: a row a line, a look's chip opens its receipt and moves its lane (drawing the row's box over a page), a file's chip opens the file (at the cite's fragment, when it has one), and a row that cites nothing reads "not read". A blob link node may carry a `fragment` the shell appends to its URL. Fields the format does not name are the run's own and ignored.
