# Rubric: Open the System Report

## Done means

- The System Information app (System Report) is open and in front, showing the report of this Mac.

## Also acceptable

- Reached any way: Apple menu › About This Mac › More Info › System Report, System Settings › General › About ›
  System Report, Spotlight, or Finder › Applications › Utilities.
- Any section of the report selected.
- System Settings or the About window left open behind it.

## Not done

- Only the About This Mac window or System Settings › General › About open, without the report.
- System Information opened and then another app brought in front of it.

## What the checks cover

- `report-in-front` reads the app in front through apps.list; it is exact for "System Information in front" and can't
  tell which section of the report is shown, which the task doesn't ask about.

## Side effects that fail the task

- Any setting changed along the way.
